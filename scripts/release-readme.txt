ToolBox {{version}}
===============

Портативный рабочий стол для сетевых и диагностических задач Windows.

Состав архива
-------------
ToolBox.exe   приложение
README.txt    этот файл
LICENSE       текст лицензии MIT

Требования
----------
- Windows 10 или Windows 11, x64.
- Microsoft Edge WebView2 Runtime.
  В Windows 11 он уже установлен. В Windows 10 может потребоваться
  отдельная установка:
  https://developer.microsoft.com/microsoft-edge/webview2/

Запуск
------
1. Распакуйте архив в папку, в которую у вас есть запись.
   Не запускайте ToolBox.exe прямо из архива.
2. Запустите ToolBox.exe.
3. При первом запуске рядом появятся каталоги local/ и profiles/.

Данные
------
- profiles/    профили; переносятся вместе с папкой программы.
- local/       настройки и служебные файлы этой машины; не синхронизируются
               и не переносятся.
- local/logs/  журналы; каталог можно удалить, приложение создаст его заново.

Чтобы перенести программу на другой компьютер, скопируйте папку целиком.
Если нужны только профили, достаточно перенести profiles/.

Обновление
----------
Закройте ToolBox и замените ToolBox.exe новой версией.
Каталоги profiles/ и local/ сохраняйте: в них данные.

Проверка файла
--------------
Файл не подписан. Windows SmartScreen может показать предупреждение
"Неизвестный издатель". Если файл скачан из доверенного источника,
разрешите запуск.

SHA256 ToolBox.exe:
{{exeSha256}}

Проверка в PowerShell:
Get-FileHash .\ToolBox.exe -Algorithm SHA256

Если не запускается
-------------------
- Установите WebView2 Runtime.
- Проверьте, что папка доступна для записи.
- Посмотрите журналы в local/logs/.
- Убедитесь, что файл скачан целиком: хеш должен совпасть.
