# 03. Поиск вкладки и память активаций

## Цель

Обычный выбор инструмента возвращает в последнюю активную вкладку с ним,
а не создаёт новую; жест «ещё одна вкладка» создаёт отдельную.

## Объём

- `src/core/services/workspace/index.ts`: память активаций в сеансе,
  `lastActiveMatching`, `focusTab`, `openTool(tool, another)`.
- Память обновляется при создании, активации, закрытии и перезапуске вкладки;
  пустые вкладки из неё забываются.
- После восстановления файла память начинается с активной вкладки.
- `another` действует только при `multipleTabs`; новая вкладка содержит один
  инструмент.
- `openSingleton` участвует в том же поиске.

## Приёмка

- Повторный выбор не увеличивает число вкладок.
- При нескольких вкладках выбирается последняя активная.
- После перезапуска — активная вкладка с инструментом, иначе самая левая.
- Пустая вкладка закрывается и при переходе в открытую.
- Память не попадает в `workspace.json`.
