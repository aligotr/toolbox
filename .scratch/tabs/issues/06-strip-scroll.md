# 06. Прокрутка полосы и подсказки рейла

**Статус:** сделано.

## Цель

Дать полосе вкладок видимую навигацию при переполнении и убрать дублирование
названия в подсказках пунктов.

## Объём

- `src/workbench/tabs/TabStrip.vue`: шевроны у кромок, градиентные кромки,
  прокрутка на 80% ширины, пересчёт при изменении ширины и числа вкладок,
  автопрокрутка к активной вкладке.
- `src/core/services/workspace/index.ts`: сигнал `focusTick` — в том числе
  для повторного выбора уже активной вкладки.
- `src/workbench/RailItem.vue`: в развёрнутом сайдбаре подсказка без названия,
  в свёрнутом — название первой строкой, пояснение следующими.
- `src/ui/theme.ts`: снят предел ширины подсказки, строки не переносятся сами.
- `src/core/infra/i18n/messages.ts`, `src-tauri/resources/languages/en.json`:
  имена шевронов для чтения с клавиатуры.
- `.agents/decisions/0043-tab-strip-scroll.md`,
  `.agents/decisions/0044-rail-tooltips.md`, `.agents/GLOSSARY.md`.

## Приёмка

- При переполнении видны шевроны только в ту сторону, где есть скрытые вкладки;
  клик прокручивает полосу, кромки показывают продолжение.
- Активная вкладка подкручивается в видимую зону, в том числе при повторном
  выборе инструмента в сайдбаре.
- Свёрнутый сайдбар и изменение окна не ломают видимость шевронов.
- В развёрнутом сайдбаре и на карточке подсказка содержит только пояснение
  жеста и занимает одну строку.
- В свёрнутом рейле название и пояснение идут разными строками.
- `npm run test`, `npm run build`, `check-messages`, `cargo check`,
  `cargo test --lib` проходят.
