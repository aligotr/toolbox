# 08. Разделить TabStrip.vue

**Статус:** не начато.

## Причина

`src/workbench/tabs/TabStrip.vue` вырос до 811 строк: script 525, template 115,
style 167. Рабочая зона Vue SFC по `.agents/rules/global/code-style.md` —
120–350 строк, порог деления — 400; блок `<style>` — до 150. Долг накопился
до задач 06–07 и вырос вместе с прокруткой полосы и шевронами.

## Объём

- Прокрутка полосы — `useStripScroll.ts`: `listEl`, видимость шевронов,
  шаг прокрутки, видимая зона активной вкладки, `ResizeObserver`.
- Меню вкладки — `useTabMenu.ts`: пункты, доступность, диалоги, подтверждение
  перезапуска.
- Стили — `<style scoped src="./tabStrip.css">`: блок остаётся scoped, но
  файл компонента разгружается.
- Шаблон — `TabItem.vue` для одной вкладки: значок, заголовок, маркеры,
  кнопки меню и закрытия.

## Приёмка

- Каждый файл в рабочей зоне, у каждого — одна названная ответственность.
- Поведение не меняется: сценарии задач 06 и 07 повторяются без расхождений.
- `npm run test`, `npm run build`, `cargo check`, `cargo test --lib` проходят.

## Блокирует

Нет. Долг по размеру файла, найден при аудите задач 06–07.
