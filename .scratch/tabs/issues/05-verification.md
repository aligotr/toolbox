# 05. Проверка

## Цель

Убедиться, что новое умолчание работает в живом окне и не сломало сборку.

## Объём

- `npm run test`, `npm run build`, `cargo check`, `cargo test --lib`.
- Живая проверка через CDP: повторный выбор инструментов, журнала и настроек;
  два DNSlookup обычным выбором и жестом; Ctrl+клик по однократным;
  перезапуск с сохранёнными дубликатами; пустая вкладка при переходе
  в открытую.
- Проверка подсказок на русском и английском.
- Обзор изменений по правилам проекта и коммит одной строкой.

## Приёмка

- Все четыре проверки проходят.
- Наблюдаемое поведение совпадает со `.scratch/tabs/spec.md`.
- В сохранённом `workspace.json` нет истории активаций.
- Замечания обзора устранены или объяснены.
