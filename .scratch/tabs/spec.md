# Одна вкладка на инструмент

## Задача

Убрать раздражающее накопление вкладок: по умолчанию выбор инструмента
в сайдбаре или на карточке должен возвращать в уже открытую вкладку, а не
открывать новую. Многовариантность остаётся возможностью отдельных
инструментов и включается осознанным жестом.

## Решения, принятые до работы

- Единственная вкладка — умолчание для всех инструментов, журнала и настроек.
- Многовариантность объявляется признаком `multipleTabs` в дескрипторе;
  отдельного признака единственности нет.
- «Последняя активная» — память активаций в сеансе, без записи в
  `workspace.json`. После перезапуска — активная вкладка, если в ней есть
  инструмент, иначе самая левая.
- Жест второго экземпляра: Ctrl+клик, средняя кнопка мыши, Ctrl+Enter.
  Для немноговариантных инструментов жест совпадает с обычным выбором.
- Подсказка о жесте — во всплывающей подсказке пункта сайдбара и карточки.
- Пустая вкладка закрывается и при переходе в уже открытую (ADR 0040).
- Старые дубликаты в файле не мигрируются и не закрываются молча.
- Подписи одинаковых вкладок не нумеруются.
- Инструмент в общей вкладке не вынимается: обычный выбор активирует всё
  рабочее место, жест открывает отдельную вкладку только с инструментом.
- Раскладку и шаблоны правило не ограничивает.
- ADR 0041 не переписывается: помечается «заменено (ADR 0042)».

## Границы

Входит: контракт инструмента, поиск вкладки в сервисе рабочего пространства,
память активаций, жесты в сайдбаре и на карточках, подсказки, словари,
документы решения и глоссарий.

Не входит: нумерация вкладок, контекстное меню «Открыть ещё», миграция
сохранённого файла, изменение раскладки и шаблонов.

## Приёмка

- Повторный выбор Busprobe, журнала, настроек и инструмента из общей вкладки
  не увеличивает число вкладок.
- DNSlookup по обычному выбору ведёт в последнюю активную вкладку с ним;
  Ctrl+клик, средняя кнопка и Ctrl+Enter открывают ещё одну.
- Ctrl+клик по Busprobe, журналу и настройкам второй вкладки не создаёт.
- После перезапуска обычный выбор ведёт в активную вкладку с инструментом,
  иначе — в самую левую.
- Пустая вкладка закрывается при переходе в открытую.
- `npm run test`, `npm run build`, `cargo check`, `cargo test --lib` проходят.
- Интерфейс проверен на русском и английском.
