# 11. Проверки

Статус: закрыт.

## Работа

- `npm run verify` зелёный: интерфейсные тесты, `vue-tsc`, сборка,
  `cargo check`, `cargo test --lib`.
- Живьём проверены удаление пресета, удаление профиля, очистка старых
  записей после удаления.
- В подтверждениях и уведомлениях нет слова «корзина».
- Стенд восстановлен: пресет возвращён в живой профиль и снова назначен
  по умолчанию.

## Критерий

Проверки повторяемы, тестовые артефакты удалены.
