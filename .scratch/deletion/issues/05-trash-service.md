# 05. Сервис корзины

Статус: закрыт.

## Работа

- `trash::stamp` ставит время удаления после `rename`.
- `trash::sweep` - единая точка чистки для запуска.
- `trash::sweep_after` чистит корзину после удаления и пропускает только
  что перенесённую запись: неудавшаяся отметка времени не превращает
  свежее удаление в просроченное.
- Чистка идёт по единице удаления: папка профиля целиком, файл пресета,
  файл словаря; пустые промежуточные папки и опустевшие ветки убираются.
- Отказы чтения и удаления пишутся в лог, запуск не блокируют.
- Событие «всё хорошо» в лог не пишется.

## Критерий

Тесты: свежая запись переживает чистку, старая удаляется, старая раскладка
чистится, пустые папки убираются, профиль с именем `presets` не сталкивается
с категорией пресетов.
