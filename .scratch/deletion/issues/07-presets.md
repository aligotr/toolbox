# 07. Удаление пресета

Статус: закрыт.

## Работа

- `presets::delete` переносит файл в
  `trash/presets/<profile>/<tool>/<id>.json`.
- Папка корзины и свободное имя готовятся до снятия умолчания.
- Указатель по умолчанию снимается до переноса файла.
- Ошибка определения профиля содержит путь.

## Критерий

Тесты: цель содержит профиль, одинаковый id из разных профилей не
смешивается, повторное удаление не перезаписывает корзину.
