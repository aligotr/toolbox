# 08. Возврат языка

Статус: закрыт.

## Работа

- `languages::revert_builtin` сначала убирает `*.missing.jsonc`, затем
  переносит словарь в `trash/languages/`.
- После переноса ставится отметка времени удаления.
- Порядок принадлежит сервису, а не команде.

## Критерий

Тесты: файл дополнений убран вместе со словарём; при отсутствии словаря
файл дополнений всё равно убран до отказа переноса.
