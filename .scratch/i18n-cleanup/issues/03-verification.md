# 03. Проверки, документы и коммит

Статус: закрыт.

## Работа

- ADR 0081 и уточнения ADR 0039, 0057, 0072, 0078.
- `.agents/rules/project/i18n.md`: ключи и файл изменений, дубли,
  `common`/`presets`, файл изменений.
- `npm run test`, `npm run build`, `npm run lint`, `cargo check`,
  `cargo test --lib`.
- Проверка раздела «Язык» в браузере: бейджи, счётчики, изменения.
- Проверка пресетов DNS и Ping после общей таблицы.
- Code review и коммит в текущую ветку.

## Проверка

- `npm run test`: 207 тестов, все прошли.
- `npm run build`: сборка, границы зон и `check-messages` прошли.
- `npm run lint`: ESLint и Prettier без замечаний.
- `cargo check`: без ошибок.
- `cargo test --lib`: 248 прошли, 1 пропущен (IPv6).
- `check-messages`: RU и EN по 633 ключа, одинаковых текстов нет.
- Браузер: «Язык», «Внешний», «Полный», файл изменений и пресеты
  DNS без сырых ключей. Ошибки `invoke` ожидаемы без Tauri IPC.

## Критерий

- Все проверки зелёные.
- В браузере нет старых подписей и потерянных ключей.
- Внешний словарь со старым ключом получает файл изменений.
