# 06. Свои серверы и системные резолверы

Blocked by: 03, 04

**Статус:** сделано (сборка и тесты; ручной сценарий — в тикете 08).

Реализовано: `servers.json` в `profiles/<id>/data/dnslookup/` через
`Storage::data_dir()`, атомарная запись, канонические адреса и проверка
дубликатов/версии; сообщения `dnslookup:servers:load/save`; диалог своих
серверов; подсказка с адресами ОС; ошибки хранения видны отдельной строкой.

## Задача

Добавить управление своими DNS-серверами с сохранением в профиль и показ
реальных системных резолверов.

## Объём

### Rust

- `servers.rs`: чтение и запись своих серверов рядом с системными
  резолверами.
- `dnslookup:servers:load` / `dnslookup:servers:load:reply` — чтение
  `profiles/<id>/data/dnslookup/servers.json` через `Storage::data_dir()`.
- `dnslookup:servers:save` / `dnslookup:servers:save:reply` — атомарная
  запись (временный файл + переименование).
- `dnslookup:system:servers` / `:reply` — адреса из `ipconfig`, без повторов.
- Формат файла: `{ "version": 1, "servers": [{ "id", "label", "address" }] }`.
- Нет файла — пустой список; битый JSON — ошибка с путём, файл не
  перезаписывается.
- Валидация адреса: IPv4, IPv4:порт, `[IPv6]:порт`; порт по умолчанию 53;
  дубликат по адресу — ошибка.

### Интерфейс

- `ServerDialog.vue`: список своих серверов с удалением, форма адреса
  и необязательного названия, ошибки валидации.
- Строка серверов: преднастроенные и свои в одном `MultiSelect`;
  выбранные — чипами; счётчик до 8.
- Добавленный сервер сразу выбран; удалённый исчезает из выбора и колонки,
  но сеанс продолжает работать с остальными.
- Системный сервер показывает подсказку с адресами; пустой список —
  «Системные резолверы не найдены».
- `status.servers.loading/error`: ошибка загрузки видна, преднастроенные
  серверы остаются доступны; сохранение не блокирует проверку.
- Свои серверы переживают перезапуск; результаты проверок — нет.

## Проверка

- Добавить `10.0.0.53:53` и перезапустить приложение — сервер есть
  в списке своих, но не выбран: выбор серверов сеансовый и после
  перезапуска возвращается к умолчанию.
- Удалить сервер — файл обновился, после перезапуска его нет.
- Ввести `999.1.1.1`, `1.1.1.1:0`, дубликат — понятная ошибка, файл
  не меняется.
- Системный сервер показывает адреса текущей машины; при отключённой сети
  список может быть пуст — подсказка корректна.
- Испортить `servers.json` вручную: ошибка видна, файл не затёрт.

## Готово, когда

- Свои серверы добавляются, сохраняются и удаляются.
- Системные адреса приходят из ОС, а не из констант.
- Ошибки хранения видны пользователю и не теряют данные.
