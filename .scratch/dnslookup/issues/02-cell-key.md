# 02. cellKey и сеансы инструментов

Blocked by: —

**Статус:** сделано.

## Задача

Дать инструментам стабильный идентификатор места в сетке, чтобы состояние
переживало переключение вкладок, а два экземпляра одного инструмента
не смешивали данные (ADR 0017).

## Объём

- `src/contracts/tools.ts`: необязательный проп `cellKey?: string`
  в контракте инструмента (тип `ToolCellProps`).
- `src/shell/WorkspaceView.vue`: передать `activeTab.id` в `ToolGrid`.
- `src/shell/ToolGrid.vue`: принять `tabId`, вычислять
  `<tabId>:<columnIndex>:<toolIndex>` и передавать `cellKey` в компонент.
- Ключ `v-for` для ячеек — `cellKey`, а не `toolId`: два одинаковых
  инструмента в одной колонке больше не конфликтуют.
- Ping не меняется: проп необязательный, состояние остаётся локальным.

## Проверка

- Открыть две вкладки с ping: у каждой свой `cellKey` (проверить через
  DevTools или временный вывод).
- Переключение вкладок не ломает ping.
- `npm run build` проходит.

## Готово, когда

- `ToolGrid` получает `tabId` и раздаёт `cellKey`.
- Контракт инструмента описывает `cellKey` без `any`.
- Закрытые вкладки не оставляют живых компонентов.

## Как выполнено

- `src/contracts/tools.ts`: добавлен `ToolCellProps { cellKey?: string }`.
- `src/shell/WorkspaceView.vue`: передаёт `:tab-id="activeTab.id"`.
- `src/shell/ToolGrid.vue`: принимает `tabId`, считает
  `<tabId>:<columnIndex>:<toolIndex>`, использует ключ для `v-for`
  и передаёт `cell-key` в компонент.
- Ping не менялся: проп необязательный, состояние остаётся локальным.

## Проверено

- `npm run build` — успешно; типы Vue и TS проходят.
- Два одинаковых инструмента в одной колонке больше не конфликтуют
  по ключу: ключ включает индекс ячейки.
