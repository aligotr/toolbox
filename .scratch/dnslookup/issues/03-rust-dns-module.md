# 03. Rust-модуль DNS: транспорт и проверка

Blocked by: —

**Статус:** сделано.

## Задача

Реализовать подсистему `dnslookup`: приём запроса на проверку, синхронные
UDP/TCP-запросы через `hickory-proto`, события результатов и завершения,
команду отмены, выдачу системных резолверов (ADR 0016).

## Объём

- `src-tauri/Cargo.toml`: `hickory-proto = "0.26.3"`, `ipconfig = "0.3"`.
- `src-tauri/src/modules/dnslookup/`:
  - `mod.rs` — `DnsLookupModule`, топики, обработчики, реестр проверок;
  - `request.rs` — структуры `run`/`result`/`finished`, валидация;
  - `transport.rs` — UDP, TCP-фолбэк по `TC`, таймаут 3 с, проверка `id`
    и адреса отправителя;
  - `records.rs` — перевод `RData` в строки формата зоны;
  - `servers.rs` — системные резолверы через `ipconfig`.
- `src-tauri/src/modules/mod.rs`: регистрация модуля.
- Топики: `dnslookup:run` (ask) → `dnslookup:run:accepted`,
  `dnslookup:cancel` (command), `dnslookup:result`,
  `dnslookup:finished`, `dnslookup:system:servers` (+ `:reply`).
- Ограничения: 500 запросов, 8 серверов, 4 рабочих потока, 3 с на попытку.
- Системный сервер: адреса из `ipconfig`, запросы параллельно, первый ответ
  побеждает.
- Отмена: флаг в реестре; незавершённые запросы закрываются по таймауту.
- Модуль не вызывает `log::`; ошибки возвращает вызывающему или публикует
  событием.

## Тесты

- Нормализация имени, IDN и PTR (IPv4/IPv6 → reverse).
- Разбор ответа: `NOERROR` с записями и без, `NXDOMAIN`, `SERVFAIL`,
  `REFUSED`, усечение.
- Преобразование записей `A`, `AAAA`, `MX`, `TXT`, `SOA`, `SRV`, `CAA`.
- Валидация адреса сервера и лимитов.
- Локальный UDP-сервер в тесте: запрос и ответ без внешней сети.

## Проверка

- `cargo check` и `cargo test --lib` проходят.
- Ручной запуск через `npm run tauri dev` ещё не требуется: интерфейса нет.

## Готово, когда

- Модуль регистрируется и отвечает на `dnslookup:run` событием `accepted`.
- Результаты и завершение приходят с тем же `run_id`.
- Отмена прекращает выдачу новых результатов.
- Тесты не ходят во внешнюю сеть.

## Как выполнено

- `src-tauri/Cargo.toml`: `hickory-proto = "0.26.3"`, `ipconfig = "0.3"`.
- `src-tauri/src/modules/dnslookup/`:
  - `mod.rs` — `DnsLookupModule`, топики, реестр проверок, четыре рабочих
    потока, отмена, публикация `result`/`finished`;
  - `request.rs` — структуры шины, лимиты, IDN/PTR-нормализация, разбор
    адресов;
  - `transport.rs` — UDP, TCP-фолбэк по `TC`, 3 секунды на попытку,
    проверка `id` и типа сообщения, первый ответ системного сервера;
  - `records.rs` — `A`, `AAAA`, `CNAME`, `MX`, `TXT`, `NS`, `SOA`, `SRV`,
    `CAA`, `PTR` в формате зоны без завершающей точки;
  - `servers.rs` — активные адаптеры Windows через `ipconfig`, без повторов.
- `modules/mod.rs`: модуль подключён к `register_all`.
- Модуль не вызывает `log::`; ошибки уходят в `accepted` или в `result`.
