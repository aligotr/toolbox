# 04. Одиночная проверка DNS

Blocked by: 01, 02, 03

**Статус:** сделано (сборка и тесты; ручной сценарий — в тикете 08).

Реализовано: экран-таблица с одной и многими строками, сеансы по `cellKey`,
запуск/остановка/очистка, лимит 500 запросов, статусы и раскрытие строки,
журнал старта и завершения. Старые результаты во время повторной проверки
показываются приглушённо.

## Задача

Собрать экран DNS в минимальном виде: одна строка, выбранные серверы,
запуск, остановка и статусы. Экран сразу строится как таблица доменов
(решение Q15): одиночная проверка — это таблица из одной строки.

## Объём

- `src/tools/dnslookup/`: `index.ts`, `api.ts`, `types.ts`,
  `constants.ts`, `normalize.ts`, `useDnslookup.ts`, `DnslookupView.vue`,
  `DnsTable.vue`.
- Дескриптор инструмента: `id: "dnslookup"`, название «DNS», иконка
  `pi pi-globe`, порядок после ping; регистрация в `src/app/tools.ts`.
- `api.ts` — единственное место `ask`, `invokeCommand`, `subscribeEvent`:
  запуск, отмена, результаты, завершение.
- Сеанс по `cellKey` в модульной карте; удаление сеансов закрытых вкладок
  при монтировании.
- Строка добавления: поле, `Select` типа, «Добавить»; добавление сразу
  запускает строку.
- Серверы: «Системный» + Google + Cloudflare по умолчанию; выбор через
  `MultiSelect`; до 8 серверов.
- Таблица: закреплённые «Домен» и «Тип», колонки серверов, `pending`,
  статусы, время ответа, раскрытие строки со всеми записями.
- «Проверить», «Остановить», «Очистить»; лимит 500 запросов проверяется
  до отправки.
- Ошибки: `status.run.error`, пустые состояния, запись в журнал о старте,
  завершении и отмене.

## Проверка

- `npm run build`, `cargo check`, `cargo test --lib`.
- `npm run tauri dev`: `example.com` / A на трёх серверах даёт три `OK`;
  несуществующий домен — `NXDOMAIN`; отключённая сеть — `НЕТ СЕТИ`.
- Переключение на журнал и обратно сохраняет строки и результаты.
- «Остановить» оставляет полученные результаты.
- Два экземпляра DNS в разных вкладках не смешивают строки.

## Готово, когда

- Одиночная проверка выполняется от ввода до ответа.
- Состояние переживает переключение вкладок и не переживает перезапуск.
- Ошибки видны в панели и в журнале.
