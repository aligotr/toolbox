# 07. Сравнение, фильтры, колонки и CSV

Blocked by: 05, 06

**Статус:** сделано (сборка; ручной сценарий — в тикете 08).

Реализовано: вердикты только по завершённым ячейкам, подсветка расхождений,
фильтры поиска/статуса/расхождений, меню «Колонки» с флажками, скрытие
колонок через список видимых серверов, счётчик расхождений в строке состояния.
CSV собирается в `useDnslookup` (свой построитель), а не `DataTable.exportCSV`:
нужны UTF-8 BOM, разделитель `;` и подписи статусов — штатный экспорт PrimeVue
пишет без BOM и с запятой. При отказе скачивания CSV копируется в буфер.

## Задача

Сделать таблицу пригодной для сравнения: расхождения с системным сервером,
фильтры, управление колонками и выгрузка.

## Объём

- Расчёт сравнения в `useDnslookup.ts`: статус и множество значений
  (порядок, регистр, TTL и точка в конце не влияют).
- Вердикт строки «совпадает у N из M» / «расходится у K из M»;
  M — серверы без системного; без системного вердикт скрыт.
- Подсветка строки с расхождением: левая полоса и приглушённый фон.
- Фильтр «Только расхождения»: без системного сервера заблокирован
  с пояснением.
- Поиск по имени без учёта регистра; фильтр статуса: все / есть ошибка /
  без ответа.
- `Column hidden` для серверных колонок; «Домен» и «Тип» скрыть нельзя;
  меню «Колонки» с флажками.
- Закреплённые «Домен» и «Тип» (`frozen`, `scrollable`).
- `exportCSV`: текущие отфильтрованные строки, видимые колонки, `;`,
  UTF-8 BOM, подписи статусов; при блокировке скачивания — копия в буфер
  и уведомление.
- Счётчик расхождений в строке состояния.

## Проверка

- Одинаковые ответы — «совпадает у 2 из 2», подсветки нет.
- Один сервер вернул `SERVFAIL` — «расходится у 1 из 2», строка подсвечена;
  фильтр оставляет только её.
- `NXDOMAIN` у всех — совпадение, фильтр «Только расхождения» строку
  не показывает.
- Снять системный сервер — вердикт исчез, переключатель заблокирован.
- Скрыть две колонки — таблица сузилась, экспорт не содержит скрытых.
- CSV открывается в Excel без кракозябр, разделитель — `;`.
- 500 строк: таблица прокручивается, фильтры не подвисают.

## Готово, когда

- Расхождение видно без чтения всех ячеек.
- Фильтры не меняют данные и не влияют на запуск проверки.
- Экспорт соответствует видимому результату.
