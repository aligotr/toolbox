# 02. Вставка видимой границы и прижатие при восстановлении

Статус: закрыт.

## Работа

- Тип `Inset`: на сколько видимая граница окна отступает от внешнего
  прямоугольника по каждой стороне.
- Измерение вставки через `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`
  для `hwnd` окна; проверка правдоподобия (0-32 px), при отказе или странных
  числах вставка нулевая.
- `fit` получает вставку: прижатие и ограничение размера считаются по
  видимой границе, размер уменьшается только если видимое окно больше
  рабочей области.
- Монитор ищется по видимой точке: прилипшее к левому или верхнему краю окно
  внешним углом выступает за рабочую область.
- Зависимость `windows` с включённым `Win32_Graphics_Dwm` только для Windows.

## Итог

Сохранённое положение, полученное прилипанием к нижнему краю, при
восстановлении не сдвигается; видимая граница не выходит за рабочую
область; остальные правила `fit` не изменились. На живой проверке окно
пережило перезапуск на месте.
