Статус: закрыт.

## Работа

Запуск `npm run tauri dev`, два монитора 1920x1080 с рабочей областью
1920x1032 (панель задач снизу), масштаб 100 %. Окно 1296x839, вставка
7 px слева, справа и снизу, 0 сверху. Второй монитор начинается с x=1920.

| Сценарий | Запрос | Результат |
|---|---|---|
| левый край | x=1915 | 1913 (видимая граница 1920) |
| порог слева | x=1900 | 1900, не прилипло |
| правый край | x=2545 | 2551 |
| порог справа | x=2538 | 2538 |
| верхний край | y=5 | 0 |
| низ над панелью задач | y=207 | 200 |
| порог снизу | y=213 | 213 |
| угол | 1915, 207 | 1913, 200 |
| вдали от краёв | 2200, 400 | без изменений |

- Настоящее перетаскивание за заголовок (инъекция мыши): окно шло за
  курсором и встало в 1913 по левому краю второго монитора, после отпускания
  осталось там же. Дёрганья и петли не видно.
- Перезапуск: окно открылось на 1913, 200, то есть прилипшее положение
  не откатилось на высоту вставки.
- В `local/settings.json` после прилипания лежат выровненные `x` и `y`.
- В логе приложения нет ошибок окна.

## Критерий

Наблюдаемое поведение совпадает со `spec.md`, в логе нет ошибок окна.
