# Языки и уведомления

Довести модель языков до двух встроенных словарей и сделать общий механизм
уведомлений. Внешние словари остаются файлами пользователя, приложение
их не переписывает.

## Решения, принятые до работы

- Встроенных языка два: `ru` (эталон) и `en`. Оба в интерфейсе, без файлов
  (ADR 0057).
- Внешний словарь - файл `local/languages/<code>.jsonc`, принадлежит
  пользователю; приложение его только читает.
- Выгрузка встроенного языка создаёт файл, только если его нет; после этого
  файл перекрывает встроенный.
- «Вернуть встроенный» переносит файл в `local/trash/languages/`.
- Цепочка отката: внешний файл → встроенный тот же код → русский → ключ.
- Недостающие ключи отдаются отдельным `<code>.missing.jsonc`: из встроенного
  того же кода или из русского. Файл детерминирован, сравнивается побайтово,
  удаляется при пустом наборе и при возврате.
- На старте проверяется только активный внешний язык; остальные - при
  открытии раздела «Язык», по «Обновить» и при возврате фокуса.
- Каталог словарей читается один раз за обращение; на старте грузится
  только активный файл.
- Уведомления: событие `core:notify`, код и параметры, один приёмник,
  PrimeVue Toast, снизу справа, не больше трёх, `group` заменяет,
  info/success 3 с, warn 5 с, error до закрытия (ADR 0058).
- Старые `<code>.json` не читаются: канон - `.jsonc` (ADR 0059).

## Что не входит

- Автообновление внешних файлов и отпечатки «правил ли пользователь».
- Дописывание ключей прямо во внешний словарь.
- Полная замена внешнего словаря кнопкой.
- Наблюдение за файлами и фоновые таймеры.
- RTL и нелатинские раскладки.

## Швы для тестов

- Чистые функции языковой модели: слияние встроенного и внешнего, подсчёт
  недостающих, выбор источника значений для `<code>.missing.jsonc`.
- Rust: каталог читает файл один раз; выгрузка не перезаписывает; возврат
  идёт в корзину; файл дополнений детерминирован и сравнивается.
- Rust: событие уведомления сериализуется с нужным топиком.
- Интерфейс: перевод с запасным текстом, ограничение очереди, замена
  по группе.

## Готово, когда

- `ru` и `en` работают без файлов; внешний `en` перекрывает встроенный
  по ключам, пропуски показывают встроенный английский.
- Выгрузка, возврат и файл дополнений работают в живом приложении.
- На старте с активным внешним языком создаётся актуальный `missing`
  и приходит одно уведомление; повторный старт молчит.
- `npm run verify` зелёный; ADR, глоссарий и правила обновлены.
