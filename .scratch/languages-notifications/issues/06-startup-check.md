# 06. Проверка на старте и уведомление

Blocked by: 02, 05

**Статус:** сделано.

## Задача

При старте с активным внешним языком проверить набор ключей, обновить
`<code>.missing.jsonc` и один раз сообщить пользователю.

## Объём

- После монтирования, не блокируя первый кадр: если активный язык внешний,
  посчитать недостающие, записать файл, сравнить с существующим.
- Файл изменился - запись в журнал и уведомление; не изменился - тишина.
- Недостающих нет - удалить устаревший файл.
- Битый активный файл: интерфейс на русском, файл дополнений не создаётся.
- Тесты: повторный старт не пишет и не уведомляет.

## Готово, когда

- Первый старт с пропусками даёт файл и одно уведомление.
- Второй старт молчит.
- После перевода ключей файл исчезает.
