# 05. Раздел «Язык»: выгрузка, возврат, дополнения

Blocked by: 03, 04

**Статус:** сделано.

## Задача

Показать два встроенных языка и внешние файлы с действиями; объяснить
правило на странице.

## Объём

- Список: бейджи «встроенный», «внешний файл», «перекрывает встроенный»,
  «битый», «нет N ключей», «полный».
- Выгрузка встроенного в `<code>.json`, только если файла нет; после
  выгрузки язык сразу внешний.
- «Вернуть встроенный»: подтверждение, файл в `local/trash/languages/`,
  включение встроенного.
- «Выгрузить недостающие»: `<code>.missing.json`, значения из встроенного
  того же кода или русского; путь и итог показываются.
- Тексты: правило «внешний словарь - ваш файл, приложение его не меняет»,
  объяснение файла дополнений.
- Ключи ru/en, проверка словарей.

## Готово, когда

- Все действия работают в живом приложении.
- Повторная выгрузка не перезаписывает существующий файл.
- Возврат не теряет файл: он в корзине.
- Недостающие ключи для `en` английские, для нового языка русские.
