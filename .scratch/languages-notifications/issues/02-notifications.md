# 02. Уведомления

Blocked by: 01

**Статус:** сделано.

## Задача

Сделать один приёмник уведомлений: событие шины от ядра и прямой вход
из интерфейса, отрисовка PrimeVue Toast по правилам ADR 0058.

## Объём

- Контракт `src/contracts/notifications.ts`: вид, код, параметры, запасной
  текст, группа.
- Rust `core/infra/notifications.rs`: тип, топик `core:notify`, публикация
  через шину.
- `src/core/infra/notifications.ts`: подписка, перевод с запасным текстом,
  ограничение очереди, замена по группе.
- `src/app/NotificationHost.vue`: `<Toast position="bottom-right" />`,
  крестик, времена, не больше трёх.
- `main.ts`: `ToastService`; `theme.ts`: вид тоста в пресете.
- Тесты: сериализация и топик в Rust; перевод, запасной текст, очередь,
  группа в интерфейсе.

## Готово, когда

- Событие `core:notify` показывает тост.
- Прямой вызов интерфейса показывает тост тем же путём.
- Четвёртое уведомление вытесняет старое, одинаковый `group` заменяет.
- `error` не исчезает сам, у всех есть крестик.

## Швы

- Rust: полезная нагрузка события и топик.
- Интерфейс: чистые функции перевода и очереди.
- Живьём: вид, положение, времена, замена.
