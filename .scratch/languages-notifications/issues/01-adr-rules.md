# 01. ADR, глоссарий и правила

Blocked by: нет

**Статус:** сделано.

## Задача

Зафиксировать модель двух встроенных языков и механизм уведомлений
до кода.

## Объём

- ADR 0057: два встроенных языка, внешние файлы, выгрузка, возврат,
  цепочка отката, файл дополнений, чтение без двойной работы.
- ADR 0058: уведомления, топик `core:notify`, полезная нагрузка, положение,
  количество, времена, группа, отсутствие истории.
- Статус ADR 0039: встроенных языков два, правило уточнено ADR 0057.
- Глоссарий: встроенный язык, внешний словарь, выгрузка, возврат, файл
  дополнений, цепочка отката, уведомление, группа, приёмник; корзина
  пополняется словарями.
- Правила интерфейса: раздел «Уведомление» с положением, количеством,
  временами, группой и запретом автотоста для `core:error`.
