# 04. Каталог и чтение без двойной работы

Blocked by: 03

**Статус:** сделано.

## Задача

Заменить список и повторную загрузку одним чтением каталога; на старте
читать только активный внешний файл.

## Объём

- Rust: `languages_catalog` читает и разбирает каждый файл один раз и
  отдаёт код, имя, проблему и сообщения; `language_load` остаётся для
  одного кода.
- Интерфейс: `languages.ts` считает `missing`/`extra` по каталогу,
  кэширует сообщения, не зовёт `language_load` для каждого файла.
- Старт с внешним языком: только `language_load(active)`.
- Возврат фокуса при открытом разделе: один проход каталога и перерисовка
  активного словаря.
- Тесты: Rust - один разбор, битый файл не роняет каталог; интерфейс -
  счётчики и слияние.

## Готово, когда

- Открытие «Языка» делает один вызов каталога.
- Внешний активный язык на старте не тянет список всех словарей.
- Счётчики совпадают с прежним поведением.
