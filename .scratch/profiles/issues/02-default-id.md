# 02. Идентификатор профиля по умолчанию из ядра

- **Состояние:** сделано

## Что сделать

- `ProfileList` получает `default_id` из ядра.
- Интерфейс убирает литерал `"work"` и берёт значение из ответа.

## Готово, когда

- Автоназвание профиля по умолчанию работает при любом `default_id`.
- Повторная загрузка списка не переименовывает профиль второй раз.

## Итог

- `profiles::DEFAULT_ID` — псевдоним `DEFAULT_PROFILE` хранилища; `ProfileList`
  отдаёт `default_id`.
- В `src/contracts/profiles.ts` добавлено поле `default_id`, в состоянии
  интерфейса — `defaultId`. Литерал `"work"` в `src/` больше не встречается.
- `nameDefaultProfile` сравнивает название с `profiles.defaultId`; флаг
  `defaultNamed` оставляет одну попытку за сеанс.
- `tests/profiles/default.test.ts`: профиль `main` переименовывается один раз,
  повторная загрузка не шлёт второй `profile_rename`, список не запрашивает
  счётчики.
