# 06. Рабочее пространство профиля

- **Состояние:** сделано

## Что сделать

- `local/workspaces/<id>.json`, путь активного профиля — у `Storage`.
- `local/workspaces/` создаётся проверкой записи.
- Уборка: удаление профиля, создание профиля, запуск.
- Старый `local/workspace.json` не читается и не мигрируется.

## Готово, когда

- У профилей разные наборы вкладок.
- Осиротевшие и посторонние файлы убираются, каталоги логируются.
- При недоступной папке профилей уборка не запускается.

## Итог

- `Storage`: `workspaces_dir`, `workspace_path` (активный профиль),
  `workspace_path_for(id)`. `probe` создаёт `local/workspaces/`.
- Сервис `workspace`: `forget(path)` и `prune(workspaces_dir, profiles_dir)`.
  `WorkspacePrune { removed, foreign }` — точка сборки только пишет лог:
  удаления на уровне `debug`, чужие объекты — `warn`.
- `prune` берёт список профилей из `profiles::ids`: недоступная папка даёт
  `errors.profiles.read`, файлы вкладок остаются. Остаются только
  `<id>.json` живых профилей; прочие файлы удаляются, каталоги и ссылки
  не трогаются (`file_type`, а не `path.is_dir()`).
- Три точки уборки: `workspace::prune` на запуске, `workspace::forget`
  в `profile_delete`, `workspace::forget` в подготовке `profile_create`.
- `profiles::create_with(dir, title, prepare)` зовёт подготовку до создания
  папки; отказ отменяет создание. Публичная обёртка `create` удалена, тесты
  используют локальный помощник, `presets.rs` — `create_with`.
- Миграции нет: старый `local/workspace.json` не читается и не удаляется
  программой.
- Тесты: путь активного профиля и `workspace_path_for`; `forget` при
  отсутствии файла; `prune` (живые файлы, осиротевшие, `*.tmp`, файл без
  расширения, каталог) и недоступная папка профилей; `create_with`
  с отказом подготовки.
