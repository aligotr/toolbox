# Экран журнала: поиск, фильтры, порядок и пауза

Согласовано с владельцем 2026-11-18. Журнал остаётся сеансовым: файла нет
(ADR 0052). Экран переделывается под чтение ленты: поиск, фильтр по источнику,
порядок, автопауза и разделители по дням. Непонятные слова «Факт» и «Ответ»
уходят из строк.

## Решения

1. **Вид записи словом не подписывается.** У каждой строки точка: серая,
   зелёная или красная. Слово «Ошибка» показывается только у отказов.
   Фильтр сводится к «Все / Только ошибки». Причина: внутренняя таксономия
   `info / result / error` пользователю ничего не говорит, а «Ответ»
   в DNS-инструменте читается как ответ сервера.
2. **Дата не занимает строку.** Дни разделяются заголовками «Сегодня»,
   «Вчера» и «18 ноября»; в строках только время. Причина: журнал живёт
   до перезапуска, поэтому дата нужна только при переходе через полночь,
   а заголовок занимает ширину один раз на день.
3. **Автопауза.** Список прокручен не в начало: новые записи не добавляются,
   появляется «Новых записей: N» и кнопка «Продолжить». Прокрутка в начало
   возобновляет ленту сама. Причина: вставка сверху толкает то, что читаешь.
4. **Порядок переключается.** По умолчанию свежие сверху; вторая позиция
   «Сначала старые». Список сортируется массивом, PrimeVue DataTable
   не вводится: журнал - лента, а не сетка.
5. **Поиск шире текста.** Ищет по переведённому тексту, источнику, коду
   и значениям параметров. Совпадения подсвечиваются в тексте. Рядом
   с фильтрами - «Показано N из M».
6. **Фильтр по источнику.** Мультивыбор `core`, `busprobe`, `dnslookup`
   со счётчиками. Пустой выбор означает «все источники».
7. **Коды записей разводятся.** Сообщение панели и запись журнала получают
   разные ключи: панель говорит повелительно, журнал - фактом.
8. **Экран опрятнее.** Описание под заголовком убирается, `DataView`
   заменяется обычным списком, фильтры переживают уход с вкладки, при
   достижении потолка показывается «Хранятся последние 200 записей».
   Подсказка источнику не нужна: источников три, и они короткие.
9. **Пустое состояние объясняет.** «Пока записей нет» дополняется тем, что
   сюда попадает: проверки, сохранения и ошибки.
10. **Очистка подтверждается.** Кнопка «Очистить» - красная, подпись слева
    от иконки. Подтверждение - всплывающий ConfirmPopup рядом с кнопкой
    («Очистить» / «Отмена»), а не модальное окно.

## Что не входит

- Сохранение журнала в файл.
- Счётчик ошибок в сайдбаре.
- Отмена очистки и выгрузка журнала.
- Раскрытие строки с кодом и параметрами.

## Критерии приёмки

1. В строке нет слов «факт» и «ответ»; у отказа видно «Ошибка».
2. Переход через полночь разделяет ленту заголовком дня; в строках нет даты.
3. Прокрутка вниз останавливает ленту и показывает число новых; прокрутка
   вверх и кнопка «Продолжить» возвращают живую ленту.
4. Порядок переключается, поиск и фильтры сужают список, счётчик показывает
   «Показано N из M».
5. Фильтры и порядок не сбрасываются при переходе на другую вкладку
   и обратно.
6. Очистка спрашивает подтверждение всплывающим блоком; отказ ничего
   не меняет, согласие очищает журнал.
7. `npm run verify` зелёный, проверка на русском и английском.

## Проверка

- `npm run verify`.
- Живая проверка: записи трёх видов, поиск, фильтр по источнику, оба порядка,
  автопауза, заголовки дней, очистка с подтверждением, смена языка.

## Сценарии тестов

Список согласуется до написания тестов (правила тестирования).

1. Поиск без совпадений отбрасывает запись: запрос не встречается ни в тексте,
   ни в источнике, ни в коде, ни в параметрах.
2. Поиск находит по коду и по параметру, а не только по переведённому тексту.
3. Фильтр «только ошибки» оставляет записи вида `error` и убирает остальные.
4. Фильтр по источнику оставляет только выбранные; пустой список - все.
5. Порядок «сначала старые» переворачивает список.
6. Записи одного дня дают один заголовок дня и ни одного разделителя между
   строками; записи двух дней дают заголовок в начале каждого дня.
7. Счётчик новых при паузе считает записи новее метки, подходящие под фильтр.
8. Подсветка делит текст на совпавшие и несовпавшие части без учёта регистра.
