# Ручной ввод положения окна

Основание: ADR 0066. Согласовано: два поля `X` и `Y` с кнопкой «Применить»,
координаты в физических пикселях, недостижимая точка прижимается к рабочей
области ближайшего монитора.

## Решение

- В разделе «Окно» карточка «Положение» - форма: подпись с пояснением
  «пиксели экрана», поля `X` и `Y`, кнопка «Применить».
- Ввод ничего не двигает. Enter применяет, Escape возвращает сохранённые
  числа. Кнопка неактивна, пока значения не изменились или пока ввод
  неверен.
- Ошибка ввода показывается у полей, а не отдельной строкой под карточкой.
- Пока положение не выбрано, поля пустые с подсказкой «Система».
- После применения поля показывают фактическое положение: если точка
  прижалась к рабочей области, числа изменятся.
- Развёрнутое, свёрнутое и полноэкранное окно перед переносом
  восстанавливается, развёрнутость снимается и в настройках.
- Размер окна не меняется: ввод задаёт только положение.

## Приёмка

- `npm run verify` зелёный: тесты, lint, `vue-tsc`, сборка, `cargo check`,
  `cargo test --lib`.
- Пока введённые числа совпадают с сохранёнными, «Применить» неактивна:
  применяется только изменение.
- Ввод точки в пределах рабочей области: окно встаёт в неё, положение
  сохраняется и переживает перезапуск.
- Ввод точки за экраном: окно прижимается к рабочей области ближайшего
  монитора видимой границей, поля показывают фактическое положение.
- Развёрнутое окно: после применения оно восстанавливается и встаёт
  в заданную точку.
- Русский и английский интерфейс показывают одинаковый набор полей
  и ошибок.

## Швы тестов

- `window::pressed_position`: точка внутри рабочей области не меняется;
  выход за каждый из четырёх краёв прижимается с учётом видимой вставки;
  окно больше рабочей области не сдвигается по этой оси.
- `window::nearest_area`: точка внутри монитора выбирает его; точка вне
  всех мониторов выбирает ближайший.
- `parseCoordinate::parseCoordinate`: целое число с пробелами по краям;
  пустое поле; дробное число; посторонний текст; значения на обеих
  границах `i32` и за ними.
- Применение к живому окну (`move_to`, команда `window_move`) юнит-тестами
  не покрывается: это адаптер к оконной системе, проверяется запуском.
