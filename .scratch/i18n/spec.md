# Мультиязычность интерфейса

Перевести на язык пользователя только то, что он видит: оболочку, настройки,
инструменты, сообщения об ошибках. Комментарии, докстринги, тесты и файловый
лог остаются русскими.

Встроенный словарь один — русский, он же эталон ключей. Любой другой язык —
файл `local/languages/<code>.json` рядом с настройками: пользователь может
перевести программу сам, не собирая её. Английский поставляется таким же
файлом и служит полигоном проверки механизма.

## Решения, принятые до работы

- Механизм свой, на `Intl`, без `vue-i18n` (ADR 0039).
- Формат словаря — JSON с комментариями и висячими запятыми; разбирает Rust.
- Цепочка отката: выбранный файл → встроенный русский → ключ.
- Журнал — структурные записи `{code, params}`, перевод при показе.
- Лог — русский навсегда.
- RTL вне области первой версии.

## Границы

Переводим: оболочку, центр управления, инструменты, статусы DNS, ошибки и
замечания из Rust, умолчания, создаваемые программой.

Не переводим: комментарии и докстринги, тесты, лог, топики, идентификаторы,
имена файлов, данные пользователя, названия-бренды (`ToolBox`, `Busprobe`,
`DNSlookup`).
