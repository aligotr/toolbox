# 02. Механизм перевода и тесты

## Цель

Свой механизм перевода на `Intl`: поиск ключа, цепочка отката, подстановки,
склонения. Без Vue внутри чистых функций, чтобы их можно было проверить
обычным `node --test`.

## Объём

- `src/core/infra/i18n/types.ts` — сообщение, параметры, каталог.
- `src/core/infra/i18n/locale.ts` — проверка тега, категория склонения,
  форматирование числа.
- `src/core/infra/i18n/translate.ts` — выбор сообщения и подстановки.
- `src/core/infra/i18n/catalog.ts` — реактивное состояние и `t()`.
- `src/core/infra/i18n/messages.ts` — русские фрагменты (эталон ключей).
- `src/core/infra/i18n/index.ts` — публичный фасад.
- `tests/i18n/*.test.ts` — тесты чистых функций (`node --test`, без vitest).
- `package.json`: скрипт `test`.
- `scripts/check-messages.mjs`: ключи из `t("…")` и `titleKey` есть в русском.

## Приёмка

- Неизвестный ключ возвращает сам ключ, а не пустую строку.
- Непереведённый ключ берётся из русского.
- Подстановки `{name}` работают со строками и числами; неизвестная
  подстановка остаётся видимой.
- Русские склонения: 1 → `one`, 2 → `few`, 5 → `many`, 21 → `one`.
- Битый тег локали не бросает исключение: склонения откатываются на русский.
- `npm run test` проходит; `npm run build` падает, если используемого ключа
  нет в русском словаре.
