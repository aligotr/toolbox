# 08. Ошибки Rust кодами

## Цель

Отделить код ошибки от русского текста: интерфейс переводит код, лог и тесты
продолжают видеть понятный русский текст.

## Объём

- `src-tauri/src/core/infra/error.rs`: `AppError { code, params, fallback }`.
- `src-tauri/src/core/`: ошибки сервисов получают код.
- `src-tauri/src/modules/`: ошибки инструментов получают код.
- `src-tauri/src/lib.rs`: команды возвращают структуру, а не строку.
- `src/core/infra/errors.ts`: разбор структуры и перевод по коду.
- Тесты сравнивают `fallback`; там, где проверяется смысл, добавляется код.
- Причина отказа разбора словаря сейчас приходит из `json5` по-английски
  («expected colon», «trailing characters»): позиция своя, причина чужая.
  Код для неё заводится здесь же — общий или по видам отказа.

## Приёмка

- Ошибка в интерфейсе переводится, в логе остаётся русской.
- Неизвестный код показывает `fallback`, а не пустоту.
- Существующие тесты не переписываются на английский.
- Журнал может получить код и параметры, а не готовую строку.
