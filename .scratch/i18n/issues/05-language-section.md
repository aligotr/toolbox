# 05. Раздел «Язык»

## Цель

Дать пользователю выбрать язык, увидеть состояние словаря и открыть папку
для правки.

## Объём

- `src/workbench/settings/sections/LanguageSection.vue`.
- `src/workbench/settings/sections.ts`: раздел `language`, `titleKey`.
- `src/workbench/settings/SettingsView.vue`: подписи через `t()`.
- Сообщения раздела в `messages.ts`.

## Приёмка

- В списке встроенный русский и найденные файлы.
- Видно, сколько ключей не переведено и какие файлы не прочитаны.
- Выбранный, но исчезнувший словарь даёт заметное предупреждение.
- Кнопки «Обновить», «Открыть папку словарей», «Выгрузить образец».
- Файл словаря не перезаписывается ни одной кнопкой.
