# 01. ADR 0039 и правила перевода

## Цель

Зафиксировать границу перевода и устройство мультиязычности так, чтобы
следующие билеты не возвращались к одним и тем же вопросам.

## Объём

- `.agents/decisions/0039-i18n.md`: граница перевода, встроенный русский,
  `local/languages/`, JSONC, свой механизм, журнал, лог, RTL.
- `.agents/GLOSSARY.md`: словарь, ключ, локаль, встроенный и внешний словарь,
  эталон, образец, подстановка, категория склонения.
- `.agents/rules/project/vue.md`: тексты интерфейса берутся из словаря.
- `.agents/rules/project/quality.md` и `agents-guard.yml`: `npm run test`.

## Приёмка

- В ADR есть решения по всем вопросам из `.scratch/i18n/spec.md`.
- Новые термины в глоссарии не дублируют существующие.
- Правила не противоречат ADR и `AGENTS.md`.
