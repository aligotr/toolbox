# 10. Проверки и документация

## Цель

Закрыть мультиязычность проверками, которые не держатся на памяти: полнота
русского, поведение механизма, приёмка на двух языках.

## Объём

- `scripts/check-messages.mjs`: полнота русского, предупреждения по внешним
  словарям, совпадение подстановок.
- `package.json`: проверка словарей в `build`, тесты в `test`.
- `.agents/rules/project/quality.md`: прогон на двух языках.
- `en.json`: покрытие всех ключей после этапов 06–09.
- Ручные сценарии: удаление файла, битый JSON, пропущенные ключи,
  испорченная подстановка, чужой язык из 20 ключей.

## Приёмка

- Сборка падает только на пропуске в русском словаре.
- Пропуск в другом словаре — предупреждение, приложение работает.
- Смена языка и перезапуск сохраняют выбор.
- `npm run test`, `npm run build`, `cargo check`, `cargo test --lib` проходят.
