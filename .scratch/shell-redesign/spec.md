# Перестройка оболочки и переход на PrimeVue

## Цель

Заменить демонстрационную оболочку рабочим пространством: сайдбар со
сворачиванием, вкладки с сеткой инструментов, шаблоны вкладок, профили,
настройки и журнал отдельными вкладками. После этого — модуль DNS.

## Что уже решено

- ADR 0009 — PrimeVue 4 как основа, свой preset, без обёрток.
- ADR 0010 — файлы вместо SQLite, `local/` и `profiles/`, профиль = папка.
- ADR 0011 — сайдбар, вкладки, колонки, шаблоны, рабочее пространство.
- ADR 0012 — слои, контракт модуля, Composition API, отказ от проверки
  реестров.
- ADR 0013 — мажор PrimeVue зафиксирован на 4: мажор 5 требует
  лицензионный ключ.

## Границы этой фичи

Входит:

- PrimeVue, тема, базовые экраны;
- оболочка: сайдбар и рейл, полоса вкладок, пустая вкладка;
- ping как первый инструмент по контракту модуля;
- журнал вкладкой;
- сервис настроек и сохранение геометрии окна;
- рабочее пространство, профили, шаблоны, привязка вкладки к шаблону;
- экран настроек как центр управления.

Не входит:

- модуль DNS (отдельная фича, начинается после этой);
- светлая тема;
- свободное дерево панелей внутри вкладки;
- перетаскивание вкладок для порядка.

## Общие требования

- Проверки перед завершением любого тикета: `npm run build`,
  `cargo check`, `cargo test --lib`.
- Комментарии и докстринги — номинативный стиль, объясняют «почему».
- Модуль не импортирует другой модуль; общение только через шину.
- Ошибка вызова видна в журнале и в панели инструмента.
- Файловый лог не используется для работы модулей.
