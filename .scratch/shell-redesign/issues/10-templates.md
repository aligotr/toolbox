# 10. Шаблоны вкладок

Blocked by: 08

**Статус:** сделано.

## Задача

Сохранять геометрию вкладки шаблоном и открывать шаблон в пустой вкладке.

## Объём

- Файл `profiles/<id>/templates/<templateId>.json`; имя файла — стабильный
  id, название внутри документа, поле `version`.
- Содержимое — только геометрия: колонки, инструменты, размеры. Введённые
  значения и результаты не сохраняются.
- Сохранение из меню вкладки: «Сохранить как шаблон» пишет новый файл.
- Применение: клик по карточке заполняет текущую пустую вкладку.
- Пустая вкладка: карточки с названием и миниатюрой раскладки.
- Управление в разделе настроек «Шаблоны»: переименовать (файл не двигается),
  дублировать, удалить в `local/trash/templates/`.
- Битый шаблон не мешает читать остальные; причина — в журнале.

## Как выполнено

- Общее правило имён вынесено в `core/names.rs`: `slug`, `unique_id`,
  `is_safe_id`. Профиль и шаблон — обе сущности «русское название плюс
  стабильный идентификатор-имя файла», и транслитерация должна быть одна:
  расхождение дало бы кириллицу в пути у одной сущности и латиницу у другой.
  `profiles.rs` теперь вызывает его, своя копия удалена.
- Rust `core/templates.rs`: `list`, `create`, `rename`, `duplicate`, `delete`.
  Содержимое `columns` не разбирается: формат колонки принадлежит интерфейсу,
  и новое свойство колонки не должно требовать правки Rust. Проверяется
  внешний договор — «это массив колонок».
- Файл `profiles/<id>/templates/<templateId>.json`: `version`, `title`,
  `columns`. Идентификатор — имя файла; переименование меняет только `title`,
  поэтому файл не двигается, а незнакомые ключи сохраняются.
- `create` собирает id транслитерацией названия, конфликт решается суффиксом
  (`dns`, `dns-2`). `duplicate` берёт геометрию исходника, а без названия
  добавляет «(копия)»: пользователь нажал одну кнопку и ждёт второй такой же
  шаблон, а не диалог.
- `delete` переносит файл в `local/trash/templates/`: промах в списке не должен
  стоить собранной раскладки. Корзина шаблонов отдельно от корзины профилей —
  сущности разные, и восстанавливать их по отдельности проще.
- `list` не падает на битом файле: пропускает его и возвращает причину
  в `warnings`, а не пишет в лог. Испорченный шаблон — факт работы подсистемы,
  его место в журнале интерфейса (ADR 0004). Чужая версия файла тоже уходит
  в замечания: молча показать шаблон, формат которого неизвестен, значило бы
  потерять его при первом сохранении.
- `storage.rs`: `templates_dir()` = `profiles/<id>/templates`,
  `templates_trash_dir()` = `local/trash/templates`. Пути собираются здесь,
  а не в командах моста.
- Команды `templates_list`, `template_create`, `template_rename`,
  `template_duplicate`, `template_delete` — в `lib.rs`; успешные операции
  пишут `info` в лог.
- TS `contracts/templates.ts`: ядро отдаёт `layout` как `unknown`, потому что
  Rust его не проверяет. Разбор колонок вынесен из `workspace.ts`
  в `core/layout.ts` (`parseColumns`, `copyColumns`, `isRecord`): один массив
  колонок приходит из файла рабочего пространства и из шаблона, и два разбора
  означали бы, что битую колонку починили только в одном месте.
- `core/templates.ts`: состояние списка и гранулярные
  `status.<операция>.loading/error`; замечания ядра пишутся в журнал.
  Общая форма состояния операции вынесена в `core/status.ts` — профили
  и шаблоны используют её вместо двух одинаковых интерфейсов.
- `core/workspace.ts`: `applyTemplate` заполняет **только пустую** вкладку —
  заполнение занятой стёрло бы текущую работу, а вернуть её было бы нечем;
  `openTemplate` открывает шаблон новой вкладкой (путь из настроек). Колонки
  копируются: правка вкладки не меняет файл шаблона.
- Меню вкладки: у рабочих вкладок появилась кнопка «⋯» с пунктом «Сохранить
  как шаблон». У пустой вкладки пункт виден, но недоступен с подписью
  «В пустой вкладке нечего сохранять»: исчезающий пункт заставил бы искать
  его в другом месте. Меню одно на полосу, пункты строятся для выбранной
  вкладки.
- `shell/SaveTemplateDialog.vue` — только сбор названия; запись делает
  сценарий оболочки. Название по умолчанию — заголовок вкладки, предел длины
  тот же, что проверяет ядро.
- `shell/EmptyTab.vue`: карточки с названием, количеством инструментов и
  миниатюрой раскладки (колонки и ячейки в тех же пропорциях). Нажатие
  заполняет текущую пустую вкладку; если она уже занята — открывает новую.
- `shell/TemplatesSection.vue`: открыть, переименовать, дублировать, удалить
  с подтверждением. Удаление спрашивает подтверждение, потому что уносит файл
  в корзину.
- `shell/plural.ts`: «1 инструмент / 2 инструмента / 5 инструментов» одной
  функцией — иначе одна из подписей говорила бы «2 инструментов».

## Проверено

- `cargo test --lib` — 75 тестов (10 на шаблоны и правило имён),
  `cargo check` — без предупреждений, `npm run build` — 268 модулей.
- В живом окне Tauri (WebView2 DevTools, настоящие клики):
  - пустая вкладка: «Сохранённых шаблонов нет», меню вкладки показывает
    недоступный пункт с подписью «В пустой вкладке нечего сохранять»;
  - вкладка Ping → меню → «Сохранить как шаблон» → диалог с названием
    «Ping» → сохранение создало `profiles/work/templates/proverka-svyazi.json`
    с `title`, `version: 1` и колонкой `ping`;
  - возврат на пустую вкладку: карточка «Проверка связи», «1 инструмент»,
    миниатюра из одной колонки; нажатие заполнило вкладку, её заголовок
    сменился на название шаблона, панель Ping работает, в `workspace.json`
    у вкладки появился `templateId`;
  - настройки, раздел «Шаблоны»: «Дублировать» создал
    `proverka-svyazi-kopiya.json` с названием «Проверка связи (копия)»;
  - переименование в «Пинг и связь» оставило файл `proverka-svyazi.json`,
    изменился только `title` внутри;
  - «Удалить» у копии унесло файл в `local/trash/templates/`, строка исчезла,
    второй шаблон остался;
  - «Открыть» создал новую вкладку «Пинг и связь» и активировал её;
  - битый `broken.json` и файл с чужой версией `future.json` не скрыли
    рабочий шаблон: он остался в списке, обе причины записаны в журнал
    («не разобран: EOF while parsing…», «версия 99, ожидалась 1»);
  - после перезапуска восстановились те же вкладки, карточка шаблона на месте,
    применение шаблона к новой пустой вкладке снова сработало.

Правка открытой вкладки шаблон не меняет по построению: при применении
колонки копируются, а файл пишется только по команде сохранения. Отдельного
органа правки раскладки пока нет — перетаскивание и привязку вкладки добавит
тикет 11, там же проверится изменение вкладки после применения.

## Готово, когда

- Сетка «DNS + Ping + Статус» сохраняется и открывается после перезапуска.
- Правка открытой вкладки не меняет шаблон.
- Удаление шаблона не ломает другие карточки.
