# 03. Журнал отдельной вкладкой

Blocked by: 02

**Статус:** сделано.

## Задача

Перенести журнал с главной в отдельную вкладку `core.journal` и оформить
его на PrimeVue.

## Объём

- `src/shell/journal/JournalView.vue` на `DataView`/`Listbox` PrimeVue.
- Запись: время, источник, вид (`info` / `result` / `error`), текст.
- Новые сверху, предел 200 записей.
- Фильтр по виду (три переключателя) и кнопка «Очистить».
- Журнал остаётся общим состоянием ядра: не привязан к вкладке и профилю.

## Как выполнено

- Экран лежит в `src/shell/JournalView.vue`: отдельная папка под один файл
  не нужна, рядом появятся другие экраны оболочки.
- Список — `DataView` в режиме `list`; вид записи — `Tag` PrimeVue
  (`info` → нейтральный, `result` → зелёный, `error` → красный).
- Фильтр — `SelectButton` с тремя вариантами, по умолчанию включены все.
  Фильтр не меняет журнал: он только сужает видимый список.
- «Очистить» живёт здесь же и вызывает `clearJournal` из core. Журнал
  по-прежнему общий: закрытие вкладки не стирает записи.
- Новые записи сверху и предел 200 уже обеспечены `core/journal.ts`.
- Карточка журнала с прежней «Главной» больше не показывается: файл
  `src/modules/home/HomeView.vue` исключён из приложения в тикете 02
  и удаляется вместе с остальными демонстрационными экранами в тикете 04.

## Проверено

- `npm run build` проходит.
- В браузере: записи трёх видов показываются, «Ошибка» отличается цветом,
  отключение вида убирает его строки, при выключенных всех видах выводится
  «Нет записей выбранного вида».
- `npm run tauri dev`: окно работает, ошибок интерфейса в логе нет.

## Готово, когда

- Журнал открывается из сайдбара и закрывается крестиком.
- Ошибка `core:error` видна в списке и отличается по виду.
- Карточка журнала с главной удалена.
