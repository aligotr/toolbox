# 02. Оболочка: сайдбар и вкладки

Blocked by: 01

**Статус:** сделано.

## Задача

Собрать каркас рабочего пространства: сайдбар со сворачиванием, полосу
вкладок, пустую вкладку. Состояние пока в памяти — сохранение в тикете 08.

## Объём

- Сайдбар: сверху инструменты (из реестра), затем «Журнал» и «Настройки»,
  внизу кнопка профиля. Свёрнутый вид — рейл 64 px, развёрнутый — 240 px,
  переключение `Ctrl+B`.
- Полоса вкладок: закрытие, активация, «+» для новой вкладки. Вкладок
  не меньше одной; закрытие последней оставляет пустую.
- Журнал и настройки — вкладки-одиночки: повторный клик переключает
  на уже открытую.
- Пустая вкладка: заголовок «Начать с шаблона», место под карточки
  шаблонов (пока заглушка), список инструментов, строка состояния ядра.
- Слой `shell` не импортирует `tools/*`; реестр приходит из точки сборки.

## Как выполнено

- Слои приведены к ADR 0012: `contracts/` (дескриптор инструмента, вкладка),
  `core/workspace.ts` (состояние и правила вкладок), `shell/` (сайдбар,
  полоса, содержимое), `app/` (точка сборки, `main.ts`, реестр).
  `index.html` теперь грузит `src/app/main.ts`.
- Правила вкладок записаны один раз в `core/workspace.ts`: повторный клик
  по журналу или настройкам активирует существующую вкладку, закрытие
  последней открывает пустую, закрытие активной активирует соседнюю.
- Инструмент пока не зарегистрирован: реестр `src/app/tools.ts` пуст,
  ping подключается в тикете 04. Сайдбар и пустая вкладка уже работают
  с дескрипторами, поэтому добавление сведётся к одной записи.
- Сайдбар 240/64 px и `Ctrl+B`. Сворачивание без анимации: `width` —
  свойство раскладки. Клавиша определяется по `event.code`, поэтому
  раскладка не важна.
- Журнал и настройки получили простые экраны, чтобы вкладки не открывались
  пустыми: список записей и сведения о запуске. Фильтры и оформление
  журнала — тикет 03, центр управления — тикет 12.
- Подсказки рейла — директива `v-tooltip` PrimeVue, зарегистрирована
  в `src/app/main.ts`.
- `src/styles/legacy.css` и временные псевдонимы токенов удалены; старые
  демонстрационные экраны `src/modules/` ещё лежат в дереве, но оболочкой
  не импортируются и удаляются в тикете 04.
- Версии `primevue` и `@primeuix/themes` приведены к точным, как требует
  ADR 0013 (`npm install` записал диапазоны `^`).

## Проверено

- `npm run build` проходит.
- В браузере: `Ctrl+B` даёт рейл 64 px и обратно 240 px; вкладки
  открываются, закрываются, последняя заменяется пустой; журнал и настройки
  не дублируются.
- `npm run tauri dev`: окно запускается, в логе нет ошибок интерфейса.

## Готово, когда

- Можно открыть и закрыть вкладки, свернуть и развернуть сайдбар.
- Оболочка не знает имён инструментов: список приходит дескрипторами.
- `npm run build` проходит.
