# 01. PrimeVue и тема

## Задача

Перевести интерфейс на PrimeVue 4: styled mode, тёмная тема, свой preset.
Старый CSS сократить до базы.

## Объём

- `package.json`: `primevue@4.5.5`, `@primeuix/themes@2.0.3`, `primeicons`.
- `src/ui/theme.ts`: `definePreset(Aura, ...)` — цвета, отступы кратными 8,
  радиусы.
- `src/main.ts`: подключение PrimeVue, пресета и тёмного класса на `html`.
- `src/styles/global.css`: только `html/body`, шрифт, фон, сброс.
- Старые стили оболочки и элементов управления — `src/styles/legacy.css`,
  импортируется из `App.vue` до тикетов 02–04.

## Как выполнено

- Мажор зафиксирован точно: PrimeVue 5 требует лицензионный ключ и без него
  показывает баннер в углу окна (ADR 0013).
- Пресет переведён на API мажора 4: тёмная шкала `surface` живёт в
  `colorScheme.dark.surface`, светлая не тронута.
- Тёмная схема включается классом `.dark` на `html` в `src/main.ts`;
  `prefers-color-scheme` на вид приложения не влияет.
- Блокирующий экран использует `Button` PrimeVue; остальные экраны временно
  остаются на `legacy.css` и переписываются в следующих тикетах.
- Размеры шрифта компонентов в PrimeVue 4 заданы в стилях самих компонентов,
  поэтому пресет отвечает за цвета, отступы, радиусы и состояния, а шкала
  28/18/15/14/13 применяется в разметке экранов.

## Готово, когда

- Приложение запускается, компоненты PrimeVue выглядят в тёмной теме.
- Цвета и отступы берутся из пресета, а не из локальных стилей.
- `npm run build` проходит.
