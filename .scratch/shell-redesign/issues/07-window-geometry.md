# 07. Геометрия окна

Blocked by: 06

**Статус:** сделано.

## Задача

Запоминать размер и положение окна, не терять окно за пределами экрана.

## Объём

- `tauri.conf.json`: 1280×800, минимум 960×640, `visible: false`.
- При старте: применить сохранённую геометрию, прижать к рабочей области
  текущего монитора, затем `show()`.
- Сохранение по `Resized`/`Moved` с задержкой ~400 мс; сброс при выходе.
- `maximized` восстанавливается отдельно от размеров.
- Кнопка «Сбросить размер и положение» в настройках (тикет 12) вызывает
  `window_reset`.
- Без `tauri-plugin-window-state`: он пишет в каталог данных приложения.

## Как выполнено

- Служба геометрии — `core/window.rs`. Состояние живёт в разделе `window`
  файла `local/settings.json` и подчиняется общим правилам записи (ADR 0010);
  плагин не подключён (ADR 0014).
- Единицы разделены по смыслу: `width`/`height` — логические пиксели,
  `x`/`y` — физические. Логический размер переживает смену масштаба экрана,
  физическая координата однозначна на общем рабочем столе.
- `fit` выбирает монитор по сохранённой точке, иначе текущий, иначе
  отбрасывает позицию; переводит размер в физические пиксели и прижимает
  **внешний** прямоугольник внутрь рабочей области монитора.
- Рамка окна измеряется у живого окна (`outer_size` − `inner_size`), а не
  задаётся числом: у этой машины она 16×39 px. Без вычета рамки окно высотой
  в рабочую область свисало бы под неё на высоту заголовка — проверено
  на первом заходе: окно 1920×1032 при рабочей области 1920×1040 уходило
  за нижний край.
- `restore` снимает развёрнутость до измерения рамки, применяет размер и место,
  затем центрирует (если места нет) и разворачивает. Возвращает
  `Restored::{AsSaved, Adjusted}`.
- Прижатие записывается обратно сразу после показа: `Adjusted` → фактическая
  геометрия уходит в файл через общий `commit_settings`, иначе прижатие
  повторялось бы при каждом запуске.
- Запись отложенная: `GeometrySaver` держит фоновый поток, события
  `Resized`/`Moved` взводят таймер на 400 мс, `CloseRequested` и
  `RunEvent::Exit` сбрасывают его принудительно и дожидаются записи.
- Снимок окна делается **в потоке событий**, фоновый поток только пишет
  готовый снимок. Геттеры окна (`is_minimized`, `inner_size`, …) отвечает
  поток событий: запрос из фонового потока повисает, если этот поток занят
  ожиданием записи. Первый заход снимал геометрию в фоновом потоке, и
  закрытие окна подвешивало приложение — `CloseRequested` ждал записи,
  запись ждала ответа потока событий. Нашлось при проверке тикета 08
  (там окно впервые закрывали по-настоящему); снимок перенесён в обработчик
  событий, сброс по-прежнему дожидается записи.
- Свёрнутое окно не пишется вовсе; у развёрнутого обновляется только
  `maximized`, обычный размер и место остаются прежними.
- `window_reset` применяет сброс немедленно тем же путём, что и старт.
- `tauri.conf.json`: метка `main`, 1280×800, минимум 960×640,
  `visible: false`; окно показывается после восстановления геометрии.
- Попутно исправлено чтение `settings.json`: файл правят руками, а «Блокнот»
  и часть редакторов сохраняют UTF-8 с BOM. `strip_bom` снимает метку,
  иначе весь файл выглядел бы испорченным (`expected value at line 1 column 1`).

## Проверено

- `cargo check` проходит без предупреждений.
- `cargo test --lib`: 45 тестов, все успешны (11 проверок геометрии).
- `npm run build` проходит.
- В живом окне Tauri (WebView2 DevTools + временный помощник user32,
  потому что права интерфейса на `set_size`/`set_position` закрыты
  `core:default`):
  - первый запуск — 1280×800, внешний угол (312, 100), по центру;
  - окно передвинуто в внешний 1132×839 @ (200, 120) → в файле
    `1116×800 @ 200,120` (клиентский размер, как и задумано);
  - перезапуск восстановил ровно эти числа;
  - разворот записал только `maximized: true`; перезапуск открылся
    развёрнутым, снятие разворота вернуло 1116×800 @ (200, 120);
  - `window_reset` → 1280×800, угол (312, 100), немедленно;
  - `width 4000, height 2000, x 5000, y 3000` (монитор отключён) →
    окно 1904×993 @ (0, 0), внешний прямоугольник 1920×1032 влезает
    в рабочую область, файл исправлен на фактическую геометрию;
  - повторный запуск стабилен: смещения нет, лишней записи нет;
  - файл с BOM прочитан целиком: 1000×700 @ (400, 293) — ОС подвинула
    окно вверх на высоту рамки, значение сохранено;
  - посторонний ключ `plugin.enabled` в файле сохранился,
    временных `*.tmp` и строк `ERROR` в логе нет.
- Закрытие окна проверено при работе над тикетом 08: пять запусков подряд
  закрывались по `WM_CLOSE` без зависания, процесс завершался, последнее
  движение окна успевало попасть в файл.

## Готово, когда

- Окно открывается в последнем размере и на последнем месте.
- После отключения монитора окно остаётся видимым.
- Первый запуск даёт 1280×800 по центру.
