# 04. Проверка удаления

**Статус:** сделано.

## Цель

Убедиться, что после удаления не осталось следов, а рабочее место работает
как прежде, кроме шаблонов.

## Объём

- Поиск по `src/` и `src-tauri/src/` на `template`, `шаблон`, `binding`,
  `bindings`; разобрать каждое совпадение.
- `npm run test`, `npm run build`, `node scripts/check-messages.mjs`,
  `cargo check`, `cargo test --lib`.
- Живое окно: запуск, пустая вкладка, выбор инструмента, меню и перезапуск,
  закрытие вкладки, настройки без «Шаблонов», профили и «Данные» без
  счётчиков, русский и английский языки.
- `workspace.json` после правки вкладки: поля `bindings` нет.

## Приёмка

- Совпадения по шаблонам остались только в исторических ADR, `.scratch/`
  и в именах, не относящихся к фиче (`*.template.json` словарей).
- Все проверки зелёные.
- Сценарии живого окна совпадают с ожиданием спеки.
