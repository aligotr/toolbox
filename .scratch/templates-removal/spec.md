# Отказ от шаблонов вкладок

## Задача

Убрать из продукта шаблоны вкладок: сохранение раскладки, привязки, раздел
настроек, карточки на пустой вкладке, команды ядра и ключи словарей. Фича
не используется, а после ADR 0042 не может воспроизвести сценарий, ради
которого задумывалась: в интерфейсе нет способа собрать многопанельную
вкладку.

## Решения, принятые до работы

- Удаление полное, а не скрытие за флагом: «спящий» код — тот же мусор,
  только с переключателем.
- Приложение не выпущено, поэтому совместимость со старым
  `workspace.json` не поддерживается: поле `bindings` и его разбор
  удаляются, а не игнорируются.
- Файлы шаблонов на диске (`profiles/<id>/templates/`) не трогаем
  и не мигрируем: после удаления они просто перестают читаться.
- Перезапуск вкладки остаётся отдельным действием. Убирается только перенос
  привязки к шаблону.
- Пустая вкладка после удаления — заголовок, список инструментов и строка
  состояния ядра. Новый блок взамен шаблонов не добавляется.
- Привязки, маркеры «изменено/обновлён», диалоги сохранения и названия,
  раздел настроек «Шаблоны», счётчики шаблонов в профилях и разделе «Данные»
  удаляются.
- Новый ADR 0046 фиксирует отказ. Старые ADR не переписываются: новая запись
  уточняет их в части шаблонов.
- Глоссарий приводится к текущему продукту: термины шаблонов удаляются,
  связанные определения поправляются.

## Границы

Входит: фронтенд-сервис шаблонов и привязок, контракты, UI полосы вкладок,
пустой вкладки и настроек, команды и модуль Rust, счётчики хранилища,
ключи русского и английского словарей, правило `i18n.md`, ADR и глоссарий.

Не входит: удаление файлов шаблонов с диска, миграция `workspace.json`,
перезапуск вкладки, пресеты настроек, профили и данные инструментов.

## Приёмка

- В интерфейсе нет ни одного упоминания шаблонов вкладок: карточек, меню,
  раздела настроек, счётчиков и маркеров.
- Пустая вкладка показывает заголовок, список инструментов и состояние ядра.
- Меню вкладки содержит только перезапуск; он по-прежнему спрашивает
  подтверждение и сохраняет раскладку.
- `workspace.json` пишется без `bindings`; файл без этого поля читается.
- `npm run test`, `npm run build`, `check-messages`, `cargo check`,
  `cargo test --lib` проходят.
- В живом окне проверены: запуск, пустая вкладка, меню и перезапуск,
  закрытие вкладки, настройки без раздела «Шаблоны», профили и «Данные»
  без счётчиков шаблонов.
