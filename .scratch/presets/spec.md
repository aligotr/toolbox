# Пресеты настроек инструментов

## Цель

Сохранять вход инструмента — строки, серверы, тип записей, фильтры — под
названием и возвращаться к нему одним действием. Первый потребитель —
DNSlookup: список доменов и набор серверов для повторяющейся проверки.

## Границы фичи

Входит:

- общий сервис ядра: конверт файла, список, создание, обновление,
  переименование, дублирование и удаление в корзину;
- хранение в `profiles/<id>/presets/<tool>/<presetId>.json`;
- пресеты в статистике профиля;
- диалог пресетов DNSlookup: загрузить, сохранить, отменить правки,
  переименовать, дублировать, удалить;
- привязка сеанса к пресету и подпись «изменён»;
- пресет по умолчанию: выбранный в диалоге пресет загружается в каждую
  новую вкладку инструмента, указатель хранится в профиле (ADR 0030);
- откат правок по снимку сеанса: настройки возвращаются без чтения файла;
- загрузка пресета отменяет текущую проверку, заменяет таблицу
  (с подтверждением) и сразу проверяет все строки.

Не входит:

- сохранение результатов проверок;
- общий экран пресетов всех инструментов;
- перенос пресета между инструментами;
- переработка заголовка и тулбара инструмента: кнопка «Пресеты» временно
  стоит отдельной строкой под фильтрами.

## Формат файла

```json
{
  "version": 1,
  "tool": "dnslookup",
  "title": "Боевые домены",
  "saved_at": "2026-11-13T11:00:00Z",
  "payload": {
    "rows": [{ "id": "…", "input": "example.com", "name": "example.com", "type": "A" }],
    "servers": ["system", "yandex"],
    "defaultType": "A",
    "hiddenServers": [],
    "filters": { "search": "", "status": "all", "diffOnly": false }
  }
}
```

`payload` разбирает инструмент. Ядро проверяет только `version`, `tool`
и то, что `payload` — JSON-объект (ADR 0028).

## Поведение

- Пресет без строк загружается: настройки применяются, проверка не
  запускается.
- Серверы, которых больше нет в профиле, пропускаются с предупреждением;
  если не осталось ни одного — берётся набор нового сеанса. Больше
  `SERVER_LIMIT` (8) серверов не выбирается: лишние отбрасываются с
  предупреждением.
- Если свои серверы не прочитаны, а в пресете есть неизвестные
  идентификаторы, загрузка отклоняется: иначе выбор пропал бы из-за
  сломанного файла.
- Неполные строки (без идентификатора, входа, имени или с незнакомым типом)
  отбрасываются с предупреждением, остальные загружаются.
- Название пресета ограничено `PRESET_TITLE_MAX_LENGTH` (60 символов) —
  тем же пределом, что проверяет ядро.
- Если в таблице есть строки или идёт проверка, замена подтверждается.
- Удаление открытого пресета снимает привязку: сохранение после этого
  создаёт новый пресет.
- Переименование меняет только название; имя файла и настройки не двигаются.
- Пресет по умолчанию назначается звёздочкой в списке пресетов. Он грузится
  при открытии инструмента в новой вкладке (сайдбар, шаблон, «+» → карточка)
  и при перезапуске вкладки; проверка запускается сразу. В уже открытую
  вкладку новая ячейка пресетом не заполняется, открытые сеансы настройка
  не трогает (ADR 0030).
- Указатель умолчания лежит в `profiles/<id>/profile.json` (`defaults`),
  удаление пресета снимает его. Пропавший или битый файл оставляет вкладку
  пустой, причина пишется в журнал.
- Сброс окна делается пунктом меню вкладки «Перезапустить вкладку»: вкладка
  заменяется копией под новым идентификатором, инструменты возвращаются
  к состоянию новой вкладки с пресетами по умолчанию, раскладка и привязка
  к шаблону сохраняются (ADR 0031).
- Откат правок возвращает настройки сохранённого пресета по снимку сеанса;
  файл не перечитывается и не меняется.
- Если состав запросов не изменился, откат восстанавливает фильтры, скрытые
  колонки и тип новых строк, а результаты остаются без повторной проверки.
  Если строки или серверы изменились, идущая проверка останавливается,
  ячейки очищаются и проверка всех строк запускается заново.
- Рядом с подписью «изменён» есть откат и быстрое сохранение: кнопка заменяет
  настройки открытого пресета, меню позволяет сохранить их новым пресетом.
- Диалог не показывает состояние «совпадает с пресетом»: подпись появляется
  только когда настройки разошлись.

## Проверка

Ручной сценарий: создать пресет из заполненной таблицы, изменить фильтр
и откатить правки без повторной проверки, изменить строку и откатить
правки с перезапуском проверки, сохранить кнопкой у подписи «изменён»,
завести из меню новый пресет, переименовать, дублировать, загрузить
с подтверждением, назначить пресет по умолчанию и открыть новую вкладку
инструмента (из сайдбара и из шаблона) — пресет загружается, проверка идёт
сразу; перезапустить вкладку из её меню — пресет грузится снова, а строки,
результаты, фильтры и привязка к пресету сброшены, раскладка и привязка
к шаблону остались; снять умолчание и убедиться, что вкладка открывается
пустой; удалить пресет по умолчанию и убедиться, что отметка снята, а вкладка
открывается пустой. Файлы — в `profiles/<id>/presets/dnslookup/`, удалённые —
в `local/trash/presets/dnslookup/`, умолчание — в
`profiles/<id>/profile.json`.
