# 03. Проверка пресетов

Blocked by: 01, 02

**Статус:** сделано.

## Задача

Проверить сборку, тесты ядра и ручной сценарий пресетов в dev-приложении.

## Объём

- `npm run build` — типы и сборка интерфейса.
- `cargo check`.
- `cargo test --lib` — 137 тестов, включая сервис пресетов и статистику
  профиля.
- Ручной сценарий в `npm run tauri dev` через CDP:
  - создать пресет из заполненной таблицы;
  - изменить фильтр — появляется «Изменён», после сохранения исчезает;
  - переименовать — название обновилось в списке и в тулбаре;
  - дублировать — появилась копия «(копия)»;
  - загрузить другой пресет при непустой таблице — подтверждение, замена,
    автозапуск проверки, восстановление фильтров;
  - удалить открытый пресет — привязка снялась, файл ушёл в корзину;
  - сохранить после удаления — создался новый пресет;
  - назначить пресет по умолчанию и открыть вкладку из сайдбара и шаблона —
    пресет загрузился, проверка пошла сразу;
  - перезапустить вкладку — пресет загрузился снова, подтверждение назвало
    пресет;
  - снять умолчание и удалить пресет по умолчанию — новые вкладки пустые,
    указатель снят.

## Готово, когда

- Сборка и тесты проходят.
- Все операции списка работают, файлы лежат по ожидаемым путям.
- Тестовые пресеты удалены из dev-профиля.
