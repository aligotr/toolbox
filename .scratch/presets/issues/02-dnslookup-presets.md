# 02. Пресеты в DNSlookup

Blocked by: 01

**Статус:** сделано.

Реализовано: `src/core/presets.ts`, `src/tools/dnslookup/presets.ts`,
`PresetsDialog.vue`, поля привязки в сеансе, кнопка пресета в шапке
с подписью загруженного пресета, откат правок по снимку.
Сброс окна вынесен в оболочку: пункт меню вкладки «Перезапустить вкладку»
(ADR 0031). Пресет по умолчанию назначается в диалоге и загружается
в свежую ячейку новой вкладки (ADR 0030). Шапка с управлением пресетом —
ADR 0032.

## Задача

Дать DNSlookup сохранение и загрузку настроек через общий сервис ядра.

## Объём

- `createPresets(tool)` в `src/core/presets.ts`: список, статусы операций,
  журнал, конвертация `saved_at`.
- Снимок сеанса: строки, серверы и их порядок, `hiddenServers`, фильтры
  `search`/`status`/`diffOnly`.
- Загрузка: отмена проверки, подтверждение замены непустой таблицы,
  пропуск отсутствующих серверов с предупреждением, запуск проверки всех
  строк.
- Привязка `presetId`/`presetTitle`/`presetSnapshot`; «изменён» — сравнение
  текущего снимка со снимком.
- Диалог: список, загрузка, сохранение в открытый пресет, откат правок,
  создание нового, переименование на месте, дублирование, удаление
  с подтверждением.
- Быстрое сохранение и откат у подписи «изменён»: заменить настройки пресета
  или вернуть сохранённые.
- Откат правок по снимку сеанса: при неизменном составе запросов результаты
  сохраняются, иначе проверка запускается заново.
- Удаление открытого пресета снимает привязку.
- Пресет по умолчанию: звезда в списке пресетов, метка «по умолчанию»,
  загрузка в свежую ячейку при открытии и перезапуске вкладки, снятие
  указателя при удалении пресета (ADR 0030).

## Проверка

Ручной сценарий из `spec.md`: создать, изменить фильтр и откатить без
перезапуска, изменить строку и откатить с перезапуском, сохранить,
переименовать, дублировать, загрузить с подтверждением, назначить пресет
по умолчанию и открыть новую вкладку, перезапустить вкладку, удалить
открытый пресет.
