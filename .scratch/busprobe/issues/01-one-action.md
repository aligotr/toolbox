# 01. Витрина шины и путь после проверки

- **Состояние:** сделано

## Что сделать

- Тексты: Busprobe как витрина, а не самопроверка.
  - `busprobe.view.lead`: «Витрина шины: учебный запрос core:ping и его путь
    до ответа core:pong.»
  - `tools.busprobe.description`: «Витрина шины и путь сообщения».
  - README и глоссарий: Busprobe как витрина шины; самопроверка как протокол.
- `useBusprobe`: объединить `check` и `trace` в одно действие. Действие
  очищает прошлую цепочку, пишет в журнал старт прогона, вызывает
  `tracedPing` (он же `ask_traced`) и заполняет ответ и круговое время;
  событие `core:trace` заполняет `chain`.
- `BusprobeView`: убрать кнопку «Показать путь» и второе состояние ошибки;
  одна кнопка запускает объединённое действие.
- Удалить `busprobe.view.showPath` и ставшие лишними ключи меток и журнала
  из русского и английского словарей.
- Дополнить ADR 0007: Busprobe как витрина, экран всегда идёт учебным
  прогоном, `ask` без задержки остаётся протоколом.
- После реализации добавить тесты по согласованному списку из спеки.

## Готово, когда

- «Проверить шину» показывает и ответ, и путь; второй кнопки нет.
- В текстах Busprobe нет слова «самопроверка» в значении экрана.
- `npm run verify` зелёный, `check-messages` не находит лишних или
  недостающих ключей.
- Ручной сценарий из спеки пройден.

## Итог

- Тексты переведены на «витрину»: заголовок экрана, описание инструмента,
  README и глоссарий. Английский словарь согласован.
- «Проверить шину» запускает `ask_traced`, заполняет ответ и очищает
  прошлую цепочку; путь приходит событием `core:trace` и показывается
  без второй кнопки.
- Удалены `busprobe.view.showPath`, `busprobe.view.badgePing`,
  `journal.busprobe.pingSent` и `journal.busprobe.traceError`. Запрос
  без задержки остался в протоколе, но не на экране.
- ADR 0007 дополнен разделом о витрине; ADR 0020 не менялся.
- Тесты: `tests/busprobe/check.test.ts` проверяет успешный прогон и отказ
  с очисткой прошлого ответа.
- `npm run verify`: 91 тест интерфейса, 168 тестов Rust, линт, сборка,
  `cargo check`; `clippy` без предупреждений.
- Ручная проверка: приложение запущено, окно открыто для просмотра.
