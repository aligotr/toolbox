# 07. Подпись пресета на карточке

Статус: закрыт.

## Работа

- Строка пресета на карточке инструмента называет роль явно:
  «Пресет по умолчанию: {title}» вместо «Пресет «{title}»».
- Английская строка - «Default preset: {title}».
- Ключ и его место в карточке не меняются: `workspace.empty.preset`
  с подстановкой `{title}`.
- ADR 0062 оставлен как запись решения: он цитирует прежнюю формулировку.

## Критерий

Карточка DNSlookup показывает «Пресет по умолчанию: Владисарт», английский
интерфейс - «Default preset: Владисарт».
