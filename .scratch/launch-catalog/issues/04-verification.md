# 04. Проверки

Статус: закрыт.

## Работа

- `npm run verify` зелёный: 114 интерфейсных тестов, lint, `vue-tsc`,
  сборка, `cargo check`, 188 тестов Rust.
- Живое окно через CDP (`127.0.0.1:9222`): раздел «Инструменты» с DNSlookup
  и строкой «Пресет «Владисарт»», раздел «Приложение» с Busprobe, журналом
  и настройками; карточки журнала и настроек открыли свои вкладки, карточка
  DNS открыла DNSlookup.
- Узкое окно 960×640: инструмент занимает строку, карточки приложения
  переносятся по две, горизонтальной прокрутки нет, «DNS‑серверов»
  остаётся одним куском.
- Английский язык: пояснение, разделы, подписи карточек и строка пресета
  переведены.
- Стенд возвращён: русский язык, одна пустая вкладка, исходный размер окна.

## Критерий

Проверки повторяемы, стенд в исходном состоянии.
