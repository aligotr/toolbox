# 03. Строка пресета по умолчанию

Статус: закрыт.

## Работа

- `core/services/presets/defaultPreset.ts`: чтение названия умолчания по
  `tool.id` без состояния пресетов.
- Пара команд домена вынесена в `readPresetFiles` и общая с держателем
  состояния пресетов.
- Отказ команды скрывает подпись и пишется в журнал
  `journal.presets.readError`; экран не падает. Битый файл пресета или
  указателя скрывает подпись, причину называет инструмент при открытии.
- Тесты: умолчания нет, умолчание есть, указатель в пустоту, отказ команды.
- Ключ `workspace.empty.preset` с подстановкой `{title}`, ru и en.

## Критерий

Карточка DNSlookup называет пресет по умолчанию, при его отсутствии строки
нет, отказ чтения виден в журнале.
