# Экран запуска как каталог

Основание: ADR 0062. Согласовано: два раздела, Busprobe в «Приложении»,
строка пресета по умолчанию, карточки разделов как быстрый запуск.

## Решение

- Экран запуска - каталог: раздел «Инструменты» (дескрипторы без
  `group: "app"`) и раздел «Приложение» (дескрипторы с `group: "app"`,
  журнал и настройки).
- Заголовок экрана остаётся «Новая вкладка»; под ним пояснение
  «Выберите инструмент или раздел приложения.».
- Разделы подписаны обычным `wb-section__title`, без капса.
- Карточка инструмента: иконка, название, строка «Пресет по умолчанию:
  {title}» при заданном умолчании, описание. Карточка приложения: иконка,
  название, описание.
- Название пресета читается оболочкой общими командами по `tool.id`
  (`preset_default_get`, `presets_list`). Инструмент о карточке не знает.
  Умолчания нет или чтение отказало - строки нет; отказ команды пишется
  в журнал кодом `journal.presets.readError`.
- Карточки журнала и настроек открывают одиночные вкладки теми же
  действиями, что и сайдбар. Ctrl+клик им не обещан.
- Описания разделов: журнал - «История событий», настройки - «Профили,
  язык, окно, журнал». Ключи живут в `SINGLETON_TABS`.
- Строка состояния ядра не меняется: точка, подпись, путь.
- Сетка: инструменты тянутся на строку (`auto-fit`), карточки приложения
  стоят плитками (`auto-fill`, минимум 280 px).

## Разногласия, закрытые работой

| Место | Было | Стало |
|---|---|---|
| ADR 0011, пункт 4 | пустая вкладка не дублирует навигацию | карточки разделов - быстрый запуск (ADR 0062) |
| ADR 0046, пункт 5 | взамен шаблонов новый блок не добавляется | добавлен раздел «Приложение», это не шаблоны |
| ADR 0037, пункт 5 | карточка-действие остаётся в `EmptyTab` | карточка вынесена в `CatalogCard`: экран использует её пять раз |
| глоссарий | пустая вкладка - список инструментов | экран запуска с каталогом и быстрым запуском |
| `ui/design.md` | правило о дублировании не сформулировано | карточки разделов - быстрый запуск, не навигация |

Старые ADR не переписываются: их уточняет ADR 0062 (правило
`global/memory.md`).

## Приёмка

- `npm run verify` зелёный: тесты, lint, `vue-tsc`, сборка, `cargo check`,
  `cargo test --lib`.
- Живое окно через CDP: два раздела, Busprobe в «Приложении», строка
  пресета у DNSlookup, карточки журнала и настроек открывают вкладки.
- Узкое окно: карточки не ломают строку, «DNS‑серверов» переносится целиком.
- Русский и английский: новые тексты и подпись пресета.

## Швы тестов

- `defaultPresetTitle`: умолчания нет, умолчание есть, указатель в пустоту,
  отказ команды (подпись скрыта, запись в журнале).
