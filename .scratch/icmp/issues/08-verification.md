# 08. Проверка

Статус: готово.

Blocked by: 06, 07.

## Работа

- `npm run verify`: тесты, линт, сборка, `cargo check`, `cargo test`.
- Тесты Rust: запрос, разрешение, оркестрация, остановка.
- Тесты TS: разбор цели, сводка, CSV, пресет, строки.
- Живая проверка: `127.0.0.1`, `::1`, внешние адреса, ошибка имени,
  остановка, пресет, обе выгрузки.
- Проверка, что словари полны и ключи не переименованы.

## Критерий

Все проверки зелёные, живой сценарий пройден, расхождений с ADR и спекой нет.

## Итог

- `npm run verify` пройден: 162 теста TS, линт, сборка, `cargo check`,
  242 теста Rust (1 пропущен).
- Живая проверка сети: `127.0.0.1` отвечает, `one.one.one.one` разрешается
  и отвечает, несуществующее имя даёт `errors.icmp.resolveFailed`.
  Временные живые тесты после проверки удалены: сеть в наборе не нужна.
- Приложение запущено с удалённой отладкой WebView2
  (`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`).
  Через CDP пройден живой сценарий: цель `127.0.0.1`, прогон 4 пакета,
  4 ответа, раскрытие показывает блоки «Адреса» и «Пакеты». Ошибок
  в консоли нет.
- Через CDP сверены размеры DNSlookup и Ping: главное поле 320, компактный
  список 104, поле параметра 92, поиск 320 при минимуме 160, кнопки строки
  24, заголовок таблицы 38, радиус таблицы 8, пустая таблица не ниже 200,
  диалог пресетов 560. Общие токены `--tool-*` и общий файл
  `src/ui/tool-layout.css` применяются в обоих инструментах (ADR 0069).
- Окно 960×640 проверено там же: документ не прокручивается по горизонтали,
  строка добавления и фильтры переносятся, таблица прокручивается внутри.
- `::1` на этой машине не проверен: IPv6 отключён (`DisabledComponents`),
  системный `ping ::1` даёт 100% потерь, `Icmp6SendEcho2` - `IP_GENERAL_FAILURE`.
  Тест IPv6 помечен `#[ignore]` и запускается на машине с включённым IPv6.
