# 03. Прогон проверки в Rust

Статус: готово.

Blocked by: 02.

## Работа

- Топики `icmp:run`, `icmp:run:accepted`, `icmp:cancel`, `icmp:resolved`,
  `icmp:packet`, `icmp:finished`.
- Проверка запроса: цели, семейство, период, количество, таймаут, пределы.
- Разрешение имён до старта пакетов, событие на цель.
- Очередь пакетов по расписанию, 16 рабочих потоков.
- Отмена через `AtomicBool`, ответы после отмены не публикуются.
- Завершение с числом отправленных и полученных пакетов.

## Критерий

Фейковый транспорт получает ровно `count` пакетов на адрес, период
соблюдается, остановка прекращает публикацию, повторный `run_id`
отклоняется.
