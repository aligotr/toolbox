# 05. Цели, таблица и раскрытие

Статус: готово.

Blocked by: 04.

## Работа

- Разбор и нормализация цели: домен через IDN, IPv4, IPv6, scope id.
- Семейство «Авто / IPv4 / IPv6», выбор для новых целей.
- Добавление, дубликат, удаление, перестановка.
- Главная строка цели: адреса, пакеты, потери, RTT, статус.
- Раскрытие: блок «Адреса» и блок «Пакеты».
- Фильтры: поиск, статус, семейство.
- Пустые состояния и сообщение о недоступной платформе.

## Критерий

Домен с A и AAAA даёт две строки адресов в раскрытии, дубликат
подсвечивается, фильтры не теряют данные.
