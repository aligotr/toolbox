- Чистое рабочее дерево после коммита.

## Критерий

Замечания разобраны, `git status` пуст, задача закрыта.

## Итог

Ревью дало 20 замечаний; исправлены все.

- Сводка: новая цель - `pending`, а не «Не разрешён»; `last` выбирается
  по времени пакета; `unreachable` не зависит от порядка адресов; отказ
  прогона даёт `error`, остановка - `cancelled`.
- Прогон: подписки создаются до запроса, частичный отказ снимает уже
  созданные обработчики; отказ и таймаут `ask` отменяют прогон в ядре;
  прогон не начинается без подписок.
- Журнал: `started` пишется только после подтверждения; причина - `AppError`,
  а не готовая фраза; добавлен `journal.icmp.startRejected`.
- Сеансы: закрытие вкладки останавливает прогон через `watch` на
  `workspace.tabs`, без раннего выхода при пустом списке.
- Пресеты: пресет по умолчанию не затирает тронутый сеанс; повтор `id`
  цели отбрасывается.
- CSV: поле, похожее на формулу, получает ведущий апостроф; отрицательное
  число остаётся числом.
- Интерфейс: снимок параметров для Escape снимается один раз и сбрасывается
  на `focusout` и `applied`; причина ошибки пакета видна в раскрытии.
- Rust: `GetLastError` читается до `IcmpCloseHandle`; выбор семейства
  и пустое разрешение вынесены в функции с тестами.

`npm run verify` пройден: 170 тестов TS, линт, сборка, `cargo check`,
246 тестов Rust (1 пропущен: IPv6 на машине отключён).

CDP-проверка на запущенном приложении: новая цель показывает «Ожидание»,
живой прогон `127.0.0.1` даёт 4 из 4 и заполняет «Последний», раскрытие
показывает «Адреса» и «Пакеты», Escape возвращает период к 1000,
ошибок в консоли нет.
