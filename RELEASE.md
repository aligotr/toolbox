# ToolBox 26.11.0

Первый выпуск ToolBox - портативного рабочего стола для сетевых и диагностических задач.

## Состав

- **DNSlookup** - проверка и сравнение ответов DNS-серверов: списки доменов,
  свои серверы, типы записей, фильтры и выгрузка в CSV.
- **Ping** - проверка отклика узлов по ICMP: домены и IP-адреса, IPv4 и IPv6,
  период и число пакетов, сводка по адресам, пакеты в раскрытии и две выгрузки CSV.
- **Busprobe** - учебная демонстрация шины: запрос, путь сообщения и ответ.

## Скачать

В релизе портативный архив:

- `ToolBox_26.11.0_portable.zip` - приложение, README и лицензия.
- `SHA256SUMS.txt` - контрольные суммы архива и `ToolBox.exe`.

## Требования

- Windows 10 или Windows 11, x64.
- Microsoft Edge WebView2 Runtime. В Windows 11 он уже установлен; в Windows 10
  может потребоваться отдельная установка:
  https://developer.microsoft.com/microsoft-edge/webview2/

## Запуск

1. Распаковать архив в папку, в которую у пользователя есть запись.
2. Запустить `ToolBox.exe`.
3. При первом запуске рядом появятся рабочие каталоги приложения.

Приложение портативное: настройки, профили и журналы лежат рядом с `ToolBox.exe`.

- `profiles/` переносится вместе с папкой программы.
- `local/` принадлежит конкретной машине: её не синхронизируют и не переносят.
- `logs/` можно удалить, приложение создаст их заново.

## Известные ограничения

- Нет автоматических обновлений: новую версию скачивают вручную.
- Нет установщика: только портативный `ToolBox.exe`.
- Подпись кода отсутствует, поэтому SmartScreen может предупреждать.
- Поддерживается Windows x64.
