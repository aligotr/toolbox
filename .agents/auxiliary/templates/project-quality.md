# Качество и завершение задачи

## Проверки

- `<тесты>` - тесты проекта.
- `<линтер>` - стиль кода и формат.
- `<сборка>` - типы, границы и сборка.
- `npm run docs:check` - ссылки, пути, ADR и глоссарий.
- `npm run docs:index` - пересобрать указатель ADR после нового решения.

Если в проекте нет Node, проверки документации переносятся на раннер проекта
или выполняются вручную.

## Проверки по области изменений

Проверяй то, что изменилось, и то, что от него зависит. Сомневаешься -
проверяй больше, а не меньше.

| Изменено | Обязательно | Не нужно |
|---|---|---|
| Документы: `.agents/**` | `npm run docs:check` | тесты и сборка: код не менялся |
| `AGENTS.md`, `README.md` | `npm run docs:check`, `<линтер>` | тесты и сборка |
| Тесты | `<тесты>`; `<линтер>`, если менялся формат | сборка |
| `<интерфейс>` | `<линтер>`, `<сборка>` | `<серверные проверки>` |
| `<сервер>` | `<серверные проверки>` | `<сборка интерфейса>` |
| Контракты и общие типы | `<тесты>`, `<сборка>`, `<серверные проверки>` | - |
| Тексты и словари | `<сборка>`, проверка языков | `<серверные проверки>` |
| Сборка и конфиги | `<полная проверка>` | - |
| Перед релизом или PR | `<полная проверка>`, `npm run docs:check` | - |

- Тест, падающий из-за окружения, не отключается: выясняется причина.
- Новое предупреждение компилятора - часть задачи, если этот компилятор
  в задаче запускался.
