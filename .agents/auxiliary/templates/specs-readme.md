# Спецификации

`.agents/specs/` - долговечные спецификации поведения. Спека отвечает на
вопрос «как система должна себя вести», а не «почему выбрали этот путь»
(это ADR) и не «что делаем сейчас» (это `.scratch/`).

## Правила

- Одна спека - один домен или крупный сценарий: `<домен>.md`.
- Статус в шапке: `действует` или `архив`.
- Спека обновляется, когда меняется поведение. История решений остаётся
  в ADR.
- При конфликте спеки и ADR главнее ADR.
- Спека не содержит списка коммитов, тикетов и временных заметок.
- Шаблон - `.agents/auxiliary/templates/spec.md`. Разделы берутся по смыслу,
  пустые не заполняются.
- Папка домена заводится, когда у одного домена появляется вторая спека:
  `specs/<домен>/`. До этого спека лежит в корне `specs/`.

## Что здесь лежит

Пока пусто. Первая спека появляется вместе с первым устойчивым поведением.
