# Глоссарий проекта

Единый словарь терминов. Имена в коде, топиках и обсуждении используют
эти слова в одном значении.

Глоссарий разбит по доменам. Один термин живёт ровно в одном файле.
Формат термина - в `.agents/glossary/README.md`.
