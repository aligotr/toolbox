# Скрипты документации

Здесь только переносные скрипты для работы с каталогом `.agents`
и документацией: проверка документации и указатель ADR. Скрипты проекта,
не относящиеся к `.agents` и документации, живут в `scripts/` в корне и в этот
каталог не попадают.

Текущий набор написан на Node и необязателен. Скрипты подключаются, если
проект готов их запускать; иначе указатель ADR ведётся вручную, а ссылки
и пути проверяются перед коммитом. Проверки кода остаются за раннером проекта.
Набор может быть дополнен реализацией на языке проекта.

- `check-docs.mjs` - проверяет ссылки, пути `.agents/`, поля ADR, указатель
  ADR, статусы спек, упоминание спек и страниц библиотеки в их README
  и согласованность глоссария. Проверяются `.agents/`, `AGENTS.md`
  и `README.md`, если они есть.
- `build-adr-index.mjs` - пересобирает `.agents/decisions/INDEX.md` по файлам
  ADR.

Запуск из корня проекта:

```powershell
node .agents/auxiliary/scripts/check-docs.mjs
node .agents/auxiliary/scripts/build-adr-index.mjs
```

В проекте с Node эти команды называются `npm run docs:check` и
`npm run docs:index`.

Скрипты не входят в ESLint и Prettier: `.agents/` исключён из проверок кода.
Их проверка - собственный запуск.

`check-docs` завершается с кодом 1, если есть проблемы. Каталоги `skills`,
`mcp`, `templates` и `node_modules` не проверяются: скилы ставит установщик,
шаблоны содержат примеры, MCP-контекст подключается отдельно.
