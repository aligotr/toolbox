# Задачи и записная книжка

`.scratch/` - временная записная книжка агента по текущей задаче. Это не
истина и не память проекта: папку можно удалить в любой момент, понимание
проекта не уменьшится.

## Правила

- `.scratch/` не попадает в git: папка в `.gitignore`.
- Одна задача - одна папка `.scratch/<задача>/`. Формат файлов свободный:
  план, заметки, чек-лист, черновики.
- Мелкая задача может не заводить папку: записная книжка нужна, когда
  без неё теряется контекст.
- Долговечное не остаётся в `.scratch/`: куда что уходит - таблица
  «Память и документы» в `AGENTS.md`.
- ADR, спеки и правила не ссылаются на `.scratch/`: ссылка переживёт
  удаление папки.
- Завершённую задачу можно удалить. Если результат отменён, удаление
  записной книжки ничего не меняет: решение и спека уже лежат в `.agents/`.

## Когда скил требует трекер

Скил может требовать GitHub Issues, внешний трекер или другой формат.
Для этого проекта трекер - `.scratch/` по правилам выше. Противоречащую
часть скила игнорируем.
