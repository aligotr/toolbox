# Приоритеты правил

Как разрешаются конфликты между источниками правил. Краткая норма —
в `AGENTS.md` → «Источник истины»; здесь — порядок действий и примеры.

## Источники

1. **`rules/global/*.md` и `rules/project/*.md`** — семантика, обоснования,
   инварианты.
2. **`agents-guard.yml`** (глобальный и проектный) — точные списки команд,
   запрещённых без явного запроса пользователя.
3. **Базовые инварианты `AGENTS.md`** — автономны, действуют даже без
   папки `.agents/`.

Глобальный и проектный YAML — один источник: списки объединяются, при
расхождении главнее проектный.

## Порядок разрешения

1. Собери действующие правила: MD и YAML из global и project. MD и YAML
   **дополняют** друг друга; global и project — тоже.
2. При расхождении global и project главнее **project**: он специфичнее.
   Глобальные правила задают умолчание, проектные уточняют под стек и продукт.
3. При конфликте MD и YAML главнее **YAML**: он точнее и проверяем. Сообщи
   пользователю о конфликте и не продолжай задачу до явного разрешения.
4. Базовые инварианты `AGENTS.md` главнее **любого файла** и продолжают
   действовать, если `.agents/` отсутствует или повреждена.
5. Правила главнее **skills**: методология skill применяется только в части,
   которая им не противоречит.

## Примеры

### Согласованные правила

- `agents-guard.yml` разрешает `npm run build`
- `quality.md` требует `npm run build` перед завершением задачи
- `AGENTS.md` запрещает откат без явного запроса
- → Правила не пересекаются: сборка обязательна, откат запрещён

### Конфликт YAML ↔ MD

- `agents-guard.yml` разрешает `npm run dev`
- `git.md` запрещает dev-сервер
- → Конфликт, YAML главнее (`npm run dev` разрешён, но это скорее всего
  ошибка в YAML — сообщить)

### Правило только в MD

- `code-style.md` говорит «все идентификаторы в camelCase»
- В `agents-guard.yml` такого правила нет
- → Применяется правило из MD: YAML не отменяет MD, а дополняет

### Правило только в YAML

- `agents-guard.yml` запрещает `rm -rf node_modules`
- В `rules/*.md` этого нет
- → Применяется правило из YAML: MD не отменяет YAML, а дополняет
