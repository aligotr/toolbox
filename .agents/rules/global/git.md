# Git

## Ветки

- `master` - защищена, force-push запрещён
- Новые фичи - в feature-ветках
- Удаление ветки: `git branch -D` - только по явному запросу

## Незакоммиченные правки

Если в `git status` видны правки, которые не делал агент - **не трогать**, спросить у пользователя о дальнейших действиях.

## Откат изменений

**Запрещено** откатывать (`git checkout --`, `git restore`, `git reset --hard`, `git stash drop`) без явного запроса владельца.

Перед любым откатом:

1. Сначала `git stash` (с явным сообщением)
2. Показать владельцу **список файлов**, которые будут откачены
3. Дождаться подтверждения
4. Если владелец не ответил - **не откатывать**

## Коммиты

- Перед коммитом выполнить все требования качества, описанные в `agents-guard.yml` текущего проекта
- Если `agents-guard.yml` отсутствует в проекте — остановиться и сообщить владельцу (проект не инициализирован для AI-агентов)
- Дополнительно: соблюсти базовые инварианты из `AGENTS.md`
- Запрещено коммитить `.env`, credentials, токены
