# Git

## Ветки

- `master` защищена: force-push **запрещён**.
- Новые фичи ведутся в feature-ветках.
- Удаление ветки (`git branch -D`) - только по явному запросу владельца.

## Незакоммиченные правки

Если в `git status` видны правки, которых агент не делал, - **не трогать**.
Сначала спросить владельца, что с ними делать.

## Откат изменений

**Запрещено** откатывать изменения (`git checkout --`, `git restore`,
`git reset --hard`, `git stash drop`) без явного запроса владельца.

Перед любым откатом:

1. Сделать `git stash` с явным сообщением.
2. Показать владельцу **список файлов**, которые будут откачены.
3. Дождаться подтверждения.
4. Если владелец не ответил - **не откатывать**.

## Коммиты

- Перед коммитом **обязательно** пройти проверки качества проекта
  и требования `agents-guard.yml`.
- Если `agents-guard.yml` отсутствует, **остановиться** и сообщить
  владельцу: проект не инициализирован для AI-агентов.
- Соблюсти базовые инварианты `AGENTS.md`.
- **Запрещено** коммитить `.env`, credentials, токены и локальные данные,
  перечисленные в `.gitignore`.
- Сообщение коммита - по-русски, в номинативном стиле, о смысле изменения.
