# Процесс: память проекта и задачи

## Память проекта

Перед архитектурными изменениями прочитай
`.agents/rules/global/memory.md`, `.agents/decisions/` и
`.agents/GLOSSARY.md`. Принятые решения не переписываются: новое оформляется
отдельным файлом по шаблону из `memory.md`. Термины проекта используй в коде,
топиках и обсуждении.

## Задачи

Задачи живут markdown-файлами в `.scratch/<фича>/`.
См. `docs/agents/issue-tracker.md`.

## Доменные документы

Single-context: глоссарий — `.agents/GLOSSARY.md`, решения —
`.agents/decisions/`. См. `docs/agents/domain.md`.

## Таблицы

Таблицы инструментов: перенос строк указателями, закреплённые колонки,
ширины колонок. См. `docs/agents/tables.md`.
