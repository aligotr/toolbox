# Качество и завершение задачи

## Обязательные проверки

Задача не завершена, пока не проходят все четыре:

```powershell
npm run test
npm run build
Set-Location src-tauri
cargo check
cargo test --lib
```

- `npm run build` включает проверку границ зон, полноту русского словаря
  и типы (`vue-tsc --noEmit`); отдельный typecheck не нужен.
- `npm run test` — тесты механизма перевода на `node --test`.
- Тест, падающий из-за окружения, не отключается: выясняется причина.
- Предупреждения компилятора не копятся: новое предупреждение — часть задачи.

## Запуск приложения

- Интерфейс проверяется запуском `npm run tauri dev`, а не только сборкой.
- Порядок проверки: запуск → основная операция инструмента → ошибка →
  закрытие и повторный запуск (проверка сохранённого состояния).
- Осиротевший процесс на порту 1420 останавливается перед новым запуском.

## Признак готовности

- Сценарий из тикета выполняется вручную от начала до конца.
- Ошибка видна пользователю: журнал + панель инструмента, без молчаливых
  кнопок.
- Состояние переживает перезапуск там, где это заявлено.
- Папка программы остаётся переносимой: новые пути — рядом с `.exe`,
  без системных каталогов.

## Лог и журнал

- Лог — только отказы приложения и его функций: старт, настройки, мост,
  файловые операции.
- Журнал — работа инструментов: запросы, результаты, отказы операций.
- Работа модуля в файловый лог не попадает.
- Новая строка лога отвечает на вопрос «почему не сработало»; событий
  «всё хорошо» в логе нет.

## Данные

- Запись — атомарная: `*.tmp` + переименование.
- Неизвестные поля в JSON сохраняются: файл могут открыть более старой
  версией.
- Повреждённый файл не роняет приложение: берутся значения по умолчанию,
  причина — в журнал и лог.
- Удаление пользовательских данных — только через корзину в `local/trash/`.

## Коммит

- Коммит делается после прохождения проверок.
- В коммит не попадают `target/`, `dist/`, `node_modules/`, `local/`.
- Сообщение коммита — по-русски, в номинативном стиле, о смысле изменения.
- Откат правок без явного запроса владельца запрещён.

## Документация

- Архитектурное решение — новый файл в `.agents/decisions/`, существующие
  не переписываются.
- Новый термин — в `.agents/GLOSSARY.md`.
- Расхождение кода и ADR считается дефектом.
