# Качество и завершение задачи

## Проверки

- `npm run test` - тесты проекта на `node --test`.
- `npm run lint` - ESLint и формат Prettier; `npm run format` переформатирует.
- `npm run build` - границы зон, полнота словарей, типы, сборка.
- `npm run docs:check` - ссылки, пути, ADR и глоссарий.
- `cargo check`, `cargo test --lib` - Rust из `src-tauri`.
- `npm run verify` - всё перечисленное сразу.

## Проверки по области изменений

Проверяй то, что изменилось, и то, что от него зависит. Сомневаешься -
проверяй больше, а не меньше.

| Изменено | Обязательно | Не нужно |
|---|---|---|
| Документы: `.agents/**` | `npm run docs:check` | тесты и сборка: код не менялся |
| `AGENTS.md`, `README.md` | `npm run docs:check`, `npx prettier --check AGENTS.md README.md` | полный `npm run lint`, тесты и сборка |
| Тесты: `tests/**` | `npm run test`; `npm run lint`, если менялся формат | cargo |
| Vue, TS и CSS в `src/` | `npm run lint`, `npm run build`; CDP, если изменилось видимое поведение | cargo: Rust не тронут |
| Только Rust в `src-tauri/` | `cargo check`, `cargo test --lib` | `npm run build`: интерфейс не тронут |
| Контракты `src/contracts/` | `npm run test`, `npm run build`, `cargo check`, `cargo test --lib` | - |
| Тексты и словари `src/core/infra/i18n/` | `npm run build`, проверка ru и en | cargo |
| Сборка и конфиги: `package.json`, `vite.config.ts`, `Cargo.toml`, `tauri.conf.json` | `npm run verify` | - |
| Перед релизом или PR | `npm run verify` | - |

- `.agents/` и `.scratch/` исключены из ESLint и Prettier: правка документов
  не даёт полезного сигнала от `npm run lint`.
- После нового ADR пересобери указатель: `npm run docs:index`.
- Тест, падающий из-за окружения, не отключается: выясняется причина.
- Новое предупреждение компилятора - часть задачи, если этот компилятор
  в задаче запускался.

## Ритм проверок

Объём и момент проверок задаёт `../../global/quality.md`. Здесь - команды
этого проекта по уровням.

| Уровень | Когда | Команды проекта |
|---|---|---|
| Точечная | одна правка, продолжение работы | `npx prettier --check <файл>`, `npx eslint <файл>`, нужный тест, `cargo check` для `src-tauri` |
| Областная | группа правок, законченный шаг, коммит | строка матрицы ниже: `npm run docs:check`, `npm run test`, `npm run build` или `cargo test --lib` |
| Полная | перед «готово», релизом, PR, изменением контрактов и конфигов | `npm run verify` и проверка через CDP |

- `npm run verify` включает линтер, сборку, тесты Node и Rust, `docs:check`.
- CDP обязателен, если изменилось видимое поведение; порядок - в `cdp.md`.
- Изменение логики без теста оставляет задачу незавершённой.

## Артефакты сборки

- Скрипт - `scripts/clean-target.mjs`, команда `npm run clean:target`.
- `npm run clean:target` - предпросмотр размера `src-tauri/target` и остатков
  прерванных сборок.
- `npm run clean:target -- --apply` - удалить остатки, инкрементальная сборка
  сохраняется.
- `npm run clean:target -- --force` - полная очистка и пересборка debug;
  с ключом `--no-build` - только очистка.
- Чистить пора, когда `target` больше 15 ГБ или в `deps` накопилось больше
  5 каталогов `.tmp*.temp-archive`.
- `target` в `.gitignore`: артефакты сборки не коммитятся.

## Запуск приложения

- Запуск нужен, только если изменилось видимое поведение.
- Интерфейс проверяется в живом окне через CDP: `npm run dev:cdp`, команды -
  в `cdp.md`. Успешная сборка не доказывает, что элемент работает.
- Порядок проверки: сценарий через `eval` и `key`, снимок экрана, `logs`,
  затем закрытие и повторный запуск.
- Ручная проверка мышью остаётся для системной рамки окна, нативных диалогов
  и реальных устройств.
- Осиротевший процесс на порту 1420 останавливается перед новым запуском.

## Что проверить вручную

- Сценарий задачи выполняется от начала до конца.
- Ошибка видна пользователю: журнал и панель инструмента, без молчаливых
  кнопок.
- Состояние переживает перезапуск там, где это заявлено.
- Папка программы остаётся переносимой: новые пути рядом с `.exe`,
  без системных каталогов.
