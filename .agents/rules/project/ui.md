# Интерфейс

Правила интерфейса разделены по вопросу, на который они отвечают:

| Файл | Вопрос |
|---|---|
| `ui/architecture.md` | Как устроены стили: кто владеет значением, где живёт правило, какие границы держат раскладку |
| `ui/design.md` | Что видно на экране и почему так: иерархия, плотность, типографика, движение |
| `ui/elements.md` | Как ведёт себя конкретный элемент: экран, шапка, строка, кнопка, подсказка, диалог, подтверждение |

Правило кладётся туда, где его будут искать. Общий принцип о стилях -
в `architecture.md`, общий принцип вида - в `design.md`, правило, которое
называет конкретный элемент, - в `elements.md`.

Основано на ADR 0009, ADR 0012, ADR 0019, ADR 0021, ADR 0022, ADR 0023,
ADR 0024, ADR 0032, ADR 0033, ADR 0037, ADR 0053 и ADR 0054.
