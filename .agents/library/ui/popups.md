# Поповеры и подтверждения

Общие всплывающие блоки у кнопки. Вызывающий отдаёт кнопку, помощник сам
находит блок, ставит его и наводит стрелку на центр. Подтверждения и
всплывающие формы о геометрии не думают (ADR 0060, ADR 0074).

## Пути

- `src/ui/primevue/popup/anchoredOverlay.ts` - положение блока и стрелка.
- `src/ui/primevue/popup/confirmPopup.ts` - тексты, кнопки и `requireConfirm`.
- `src/core/constants.ts` - наборы `CONFIRM_DANGER_ACCEPT`,
  `CONFIRM_PRIMARY_ACCEPT`, `CONFIRM_CALM_REJECT`.

## Подтверждение

```ts
import { useConfirm } from "primevue/useconfirm";
import { requireConfirm } from "@/ui/primevue/popup/confirmPopup";

const confirm = useConfirm();

requireConfirm(confirm, {
  target: button,
  message: t("..."),
  acceptLabel: t("..."),
  rejectLabel: t("..."),
  accept: () => {
    // действие
  },
});
```

`ConfirmRequest`:

- `target` - кнопка, у которой встаёт блок;
- `message` - короткий вопрос, называет предмет;
- `acceptLabel`, `rejectLabel` - подписи кнопок;
- `acceptProps`, `rejectProps` - вид кнопок; по умолчанию опасный и спокойный;
- `accept` - обработчик согласия.

`requireConfirm` сам зовёт `anchorOverlay(target, "confirm")`.

## Всплывающая форма

```ts
import { anchorOverlay } from "@/ui/primevue/popup/anchoredOverlay";

function onShow(event: Event) {
  anchorOverlay(event.currentTarget as HTMLElement, "popover");
}
```

`anchorOverlay` принимает кнопку и вид блока: `"confirm"` или `"popover"`.
Внутри он ждёт появления блока, у подтверждения ставит его сам и наводит
стрелку. Поправка повторяется, пока стрелка не устоится: у края окна блок
пересчитывается уже после показа.

## Геометрия

- Блок встаёт по центру кнопки, стрелка указывает на центр кнопки, а не на
  её край. У края окна блок прижимается внутрь.
- Клик внутри подтверждения не сдвигает блок. PrimeVue на любой клик внутри
  зовёт свой `alignOverlay` и возвращает стандартное положение. Поэтому
  `anchorOverlay` ставит обработчик на сам блок и повторяет центрирование
  в кадре отрисовки.
- Микрозадача не годится: Chromium выполняет её сразу после обработчика
  блока, до всплытия клика до `document`. Кадр идёт после обработчика
  документа и до отрисовки, скачка не видно.
- Проверять такое поведение нужно настоящим кликом. Синтетический
  `dispatchEvent` скрывает разницу.

## Ограничения

- Модальный диалог закрывается кликом по пустому месту вокруг него.
  Всплывающее подтверждение так не закрывается: у него нет содержимого,
  которое можно потерять, а ответ спрашивают намеренно.
- Всплывающий блок формы закрывается кликом мимо сам.
- Подтверждение не заменяет модальный диалог, если действие перезапускает
  приложение или не привязано к кнопке. Переключение профиля остаётся
  модальным диалогом.
