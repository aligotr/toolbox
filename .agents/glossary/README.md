# Файлы глоссария

Термины лежат по доменам. Один термин живёт ровно в одном файле.
Имя файла - домен: `core.md`, `ui.md`, `tools.md`.

Формат термина:

```markdown
**Термин** - значение в одном-двух предложениях. Детали реализации не
описываются.
```

Правила:

- Новый термин добавляется в подходящий файл и в указатель
  `.agents/GLOSSARY.md`.
- Один термин - один файл. Дубли не допускаются.
- Если термин в коде и обсуждении называется по-разному, побеждает глоссарий.
- Заголовок файла и вступительная строка называют домен.
