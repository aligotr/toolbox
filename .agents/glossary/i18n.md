# Глоссарий: Мультиязычность

Языки, словари, ключи, подстановки и формы.

**Язык интерфейса** - язык, на котором программа говорит с конечным
пользователем. Хранится в `local/settings.json` разделом `ui.language`;
`null` - «как в системе», выбор определяется при первом запуске и
сохраняется. Не путать с языком кода: комментарии, тесты и лог остаются
русскими (ADR 0039).

**Локаль** - тег BCP 47 (`ru`, `en`, `pt-BR`), который выбирает формы
склонения и формат чисел и дат. Совпадает с именем файла внешнего словаря.

**Словарь** - набор сообщений интерфейса по ключам. Встроенных словаря два:
`ru` (эталон) и `en`; оба живут в интерфейсе и не требуют файлов. Внешний
словарь - файл `local/languages/<code>.jsonc`, который пользователь правит
руками; он перекрывает встроенный язык с тем же кодом. Приложение внешние
файлы никогда не перезаписывает (ADR 0039, ADR 0057).

**Встроенный язык** - `ru` или `en`, поставляемый вместе с программой.
Не требует файла, всегда полон и обновляется вместе с приложением.

**Внешний словарь** - файл `local/languages/<code>.jsonc`, принадлежащий
пользователю. Появляется по кнопке выгрузки у встроенного языка или
создаётся вручную для нового языка. Приложение его только читает.

**Выгрузка языка** - создание внешнего словаря из встроенного по кнопке
раздела «Язык». Файл создаётся, только если его ещё нет; после выгрузки
язык становится внешним и перекрывает встроенный.

**Возврат к встроенному** - перенос внешнего словаря в
`local/trash/languages/` и возврат к встроенному языку с тем же кодом.

**Файл изменений** - `<code>.updates.jsonc` рядом со словарём: `add`
содержит ключи, которых нет в словаре или у которых не хватает форм,
а `remove` - ключи, которых больше нет в программе. Создаётся
программой, словарём не считается и может перезаписываться (ADR 0057,
ADR 0081).

**Цепочка отката словаря** - внешний файл → встроенный язык с тем же кодом
→ русский эталон → ключ.

**Эталонный словарь** - русский встроенный словарь: он обязан быть полным,
и только его пропуск валит сборку. Остальные словари могут отставать.

**Образец словаря** - файл `<code>.template.jsonc`, выгруженный кнопкой
раздела «Язык». Копия эталонного словаря для начала перевода; создаётся
только если файла ещё нет.

**Ключ словаря** - имя сообщения: `область.сущность.поле`
(`settings.language.title`, `errors.files.read`). Ключ - адрес строки
в текущей версии: его можно переименовать или слить напрямую. Изменение
попадает в файл изменений как `add` и `remove`; автоматического переноса
перевода нет (ADR 0081).

**Сообщение словаря** - значение по ключу: строка или набор форм по
категориям склонения. Подстановка записывается как `{name}`; другого
синтаксиса нет.

**Подстановка** - именованное значение внутри сообщения (`{count}`,
`{path}`). Числа форматируются по локали; неизвестное имя остаётся
видимым, чтобы ошибку перевода было легко заметить.

**Категория склонения** - форма сообщения по правилам CLDR: `zero`, `one`,
`two`, `few`, `many`, `other`. Выбирается через `Intl.PluralRules`;
русскому нужны `one`, `few`, `many`, английскому - `one`, `other`.

**Отчёт словаря** - число непереведённых и лишних ключей внешнего файла,
а также причина, по которой файл не прочитан. Показывается в разделе
«Язык»; неполнота внешнего словаря работу не останавливает.
