# Языки и словари: спецификация

- **Статус:** действует
- **Область:** `src/core/infra/i18n/`, `src/core/services/languages/`,
  `src/workbench/settings/sections/LanguageSection.vue`, `local/languages/`
- **ADR:** 0039, 0057, 0081

## Встроенные словари

- Русский `src/core/infra/i18n/messages.ts` - эталон ключей, обязателен
  всегда.
- Английский `src/core/infra/i18n/messages.en.ts` - второй встроенный
  словарь, тоже полный.
- Оба лежат в интерфейсе и не требуют файлов.

## Внешние словари

- Файл `local/languages/<code>.jsonc` с полями `name` и `messages`.
- Перекрывает встроенный язык с тем же кодом.
- Программа его не перезаписывает и только читает.
- Новый язык не требует правки кода.
- Выгрузка языка создаёт файл, только если его ещё нет; после выгрузки
  язык становится внешним.
- Возврат к встроенному переносит файл в `local/trash/languages/`.
- Образец `<code>.template.jsonc` - копия эталонного словаря для начала
  перевода; создаётся, только если файла ещё нет.

## Файл изменений

- `<code>.updates.jsonc` лежит рядом со словарём.
- `add` содержит ключи, которых нет в словаре или у которых не хватает форм.
- `remove` содержит ключи, которых больше нет в программе.
- Создаётся программой, словарём не считается и может перезаписываться.
- Обновляется, когда язык активен: на старте и при переключении; для
  остальных словарей - по кнопке выгрузки.

## Цепочка отката

Внешний файл → встроенный язык с тем же кодом → русский эталон → ключ.
Пропуск ключа показывает встроенный язык, иначе русский. Откат виден как
непереведённое место.

## Категории склонения

- Категории CLDR: `zero`, `one`, `two`, `few`, `many`, `other`.
- Выбор идёт через `Intl.PluralRules`.
- Русскому нужны `one`, `few`, `many`, `other`; английскому - `one`,
  `other`. `other` обязательна всегда.

## Отчёт

- Отчёт показывает число непереведённых и лишних ключей внешнего файла
  и причину, по которой файл не прочитан.
- Отчёт виден в разделе «Язык».
- Неполнота внешнего словаря работу не останавливает.

## Проверка

- `npm run build` запускает `scripts/check-messages.mjs`.
- Оба встроенных словаря полны и совпадают по ключам, подстановкам и формам.
- Одинаковые тексты внутри словаря запрещены.
- Внешние словари проверяются в разделе «Язык» на добавляемые и устаревшие
  ключи, подстановки и формы.
