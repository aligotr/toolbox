# Архив спецификаций

Эти файлы перенесены из `.scratch/` как архив: на них ссылаются ADR.
Они описывают поведение на момент решения и не являются правилами.
Источник истины по решению - ADR; при расхождении главнее ADR.

Пополнять архив задачами из `.scratch/` не нужно. Новые спеки пишутся
в `.agents/specs/` по шаблону `.agents/auxiliary/templates/spec.md`.
