# Удаление перезапуска вкладки

Перезапуск вкладки не нашёл применения. Действие удаляется целиком, без
замены на контекстное меню: кнопка с тремя точками, меню, подтверждение,
сервис и тексты уходят. Решение записано в ADR 0051.

## Что входит

- Удаление кнопки с тремя точками в `TabItem.vue` и меню в `TabStrip.vue`.
- Удаление `useTabRestart.ts` и подтверждения перезапуска.
- Удаление `restartTab` и `renameTab` из сервиса рабочего пространства.
- Удаление `defaultPresetTitle` и `loadPresetDefaults`, которые жили только
  ради подсказки в подтверждении.
- Удаление ключей словарей: меню вкладки, пункт перезапуска, тексты
  подтверждения, записи журнала о перезапуске.
- Удаление тестов перезапуска; проверка свежих ячеек переносится на открытие
  новой вкладки.
- ADR 0051 и пометка ADR 0031 отменённым.
- Чистка глоссария и комментариев, которые обещают перезапуск.

## Что не входит

- Контекстное меню по ПКМ.
- Сброс состояния внутри инструментов.
- Изменение загрузки пресета по умолчанию при открытии вкладки.
- Изменение закрытия вкладки и восстановления рабочего пространства.

## Критерии приёмки

1. На вкладке нет кнопки с тремя точками, меню вкладки нет.
2. В коде нет `restartTab`, `renameTab`, `useTabRestart`,
   `defaultPresetTitle`, `loadPresetDefaults`.
3. Закрытие вкладки по-прежнему очищает сеансы, открытие новой вкладки
   по-прежнему загружает пресет по умолчанию.
4. В словарях нет ключей перезапуска и меню вкладки; `check-messages` зелёный.
5. `npm run verify` зелёный; ручная проверка на живом окне.
6. Глоссарий и ADR не обещают удалённую функцию.

## Проверка

- `npm run verify`.
- Ручная: на вкладке нет кнопки меню; закрытие и открытие инструмента
  возвращают его к началу; пресет по умолчанию загружается в новую вкладку.

## Сценарии тестов

Согласованы до реализации.

1. Открытие новой вкладки помечает ячейку свежей ровно один раз:
   `openTool` плюс `takeFreshCell`.
2. Пресет по умолчанию запоминается и снимается: `state.defaultId`
   после `setDefault` и `setDefault(null)`. Проверка `defaultPresetTitle`
   удаляется вместе с функцией.

Тесты перезапуска удаляются: проверять нечего.
