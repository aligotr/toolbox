# ADR 0013: Мажорная версия PrimeVue зафиксирована на 4

- **Статус:** принято (восстановлено ADR 0018)
- **Дата:** 2026-11-12
- **Область:** `package.json`, `src/main.ts`, `src/ui/theme.ts`

## Контекст

ADR 0009 выбрал PrimeVue 4 как основу интерфейса. При установке `npm install
primevue` ставится мажор 5: он объявлен тегом `latest`.

PrimeVue 5 распространяется по PrimeUI License и на старте проверяет ключ.
Без ключа проверка возвращает `missing`, а плагин сам вставляет в правый
нижний угол окна баннер «Invalid PrimeUI License». Баннер живёт в закрытом
shadow root, не подчиняется стилям приложения и не отключается настройкой.
Для личного переносимого инструмента это неприемлемо: приложение показывало
бы чужую рекламную плашку поверх рабочей области.

В PrimeVue 4 такой проверки нет, тема задаётся тем же способом, что описан
в ADR 0009.

## Решение

Версия зафиксирована точно: `primevue@4.5.5`, `@primeuix/themes@2.0.3`.
Диапазон `^` не используется: `npm install primevue` без версии снова
поставит мажор 5.

Обновление до 5 возможно только вместе с лицензионным ключом; это отдельное
решение, а не побочный эффект установки зависимости.

## Почему так

- ADR 0009 описывает API мажора 4: `darkModeSelector`, `colorScheme.dark`,
  пресет Aura. Мажор 5 перешёл на `light-dark()` и другой набор опций темы —
  пресет пришлось бы переписывать.
- Плашка лицензии появляется в рантайме и не видна ни в сборке, ни в типах.
  Ошибка обнаружилась бы только при запуске приложения.
- Точная версия делает сборку воспроизводимой: у коллег, копирующих папку,
  и на машине владельца один и тот же код.

## Последствия

- `package.json` держит точные версии PrimeVue и темы.
- Обновление мажора — отдельная задача с проверкой лицензии и переписыванием
  пресета.
- Компоненты импортируются поимённо (`import Button from "primevue/button"`):
  авто-регистрации в PrimeVue нет, резолвер не устанавливается (ADR 0009).

## Отклонённые альтернативы

- **Оставить мажор 5 и скрыть баннер CSS.** Баннер в закрытом shadow root;
  обход — гонка со стилями и нарушение лицензии. Отклонено.
- **Мажор 5 с ключом.** Ключа нет; покупка ради личного инструмента не
  оправдана.
- **Диапазон `^4.5.5`.** Разрешает установку 5.x при обновлении зависимостей
  и возвращает ту же проблему. Отклонено.
