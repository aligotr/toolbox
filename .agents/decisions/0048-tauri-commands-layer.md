# ADR 0048: Команды Tauri — отдельный слой `core/commands/`

- **Статус:** принято
- **Дата:** 2026-11-17
- **Область:** `src-tauri/src/lib.rs`, `src-tauri/src/core/commands/`,
  `src-tauri/src/core/runtime.rs`, `.agents/rules/project/architecture.md`

## Контекст

`src-tauri/src/lib.rs` вырос до 1117 строк и смешал четыре вещи:
сборку зависимостей (`boot`), реализацию `EventSink`, команды интерфейса
(34 штуки) и жизненный цикл окна. Файл стал единственным местом, куда
приходит правка при добавлении любой команды, — даже если меняется
одно поле в ответе.

Вместе с размером вылезли нарушения правила «правило домена в `lib.rs` →
в сервис» (`architecture.md`). Например, запрет удаления активного профиля
живёт в команде `profile_delete`, а не в `profiles`. Пока команды лежат
рядом со сборкой, это выглядит нормой: сервисы не видят границы, а точка
сборки обрастает поведением.

## Решение

1. **Команды живут в `src-tauri/src/core/commands/`, по файлу на область.**
   `bridge.rs` (мост шины), `workspace.rs`, `profiles.rs`, `presets.rs`,
   `languages.rs`, `settings.rs` (настройки и их побочные эффекты),
   `info.rs` (сведения, данные, папки), `window.rs` (команда сброса
   и жизненный цикл окна), `lifecycle.rs` (прямые команды жизненного цикла).

2. **Команда — адаптер, а не домен.** Её работа: разобрать аргументы,
   получить хранилище из состояния запуска, позвать сервис, записать
   побочный эффект (лог, событие). Правило, которое отвечает «можно ли
   так», остаётся в сервисе. Проверка активного профиля переносится
   в `profiles::delete`.

3. **Состояние запуска переезжает в `core/runtime.rs`.** `Runtime`,
   `StartupError` и доступ к хранилищу (`require_storage`) — это то, что
   читают команды. Создаёт его точка сборки; поля остаются закрытыми
   для остального крейта.

4. **`lib.rs` оставляет сборку и регистрацию.** В нём остаются `boot`,
   `blocked`, `TauriSink`, `run` со списком `generate_handler!` и обработкой
   `RunEvent::Exit`. Ни одной команды и ни одного правила домена.

5. **Зависимость односторонняя: `commands → services → store → infra`.**
   Обратной стрелки нет: сервис не знает, что его зовут из Tauri. Границу
   проверяет `core::zone_tests`, чтобы она не осталась договором на словах.

6. **Жизненный цикл окна остаётся рядом с командой окна.** Восстановление
   геометрии вызывают и `setup`, и команда `window_reset`; одна копия
   правила обязана жить в одном месте. Это адаптер к окну ОС, а не домен,
   поэтому `commands/window.rs`, а не `services`.

## Почему так

- **Точка сборки перестаёт быть местом правки каждой команды.** Новая
  команда добавляет строку в свой файл и строку в список регистрации;
  `lib.rs` меняется только при изменении порядка запуска.
- **Область видна по имени файла.** `presets.rs` рядом с `presets::list`
  читается быстрее, чем тридцать четыре функции подряд.
- **Правило возвращается в сервис.** `profiles::delete` сам решает,
  что активный профиль удалять нельзя; команда только передаёт `id`.
- **Состояние запуска — не домен.** `Runtime` не должен попадать в зоны
  `services` или `store`: его поля — пути, логгер и мьютексы, нужные
  только адаптеру.

## Последствия

- `lib.rs` сокращается примерно до 300 строк: сборка, блокировка,
  мост событий, регистрация команд и обработка выхода.
- Команды получают `pub(crate)`: снаружи крейта они не нужны.
- Новый файл команды добавляется в `commands/mod.rs`; новый домен —
  по-прежнему в `services`.
- `core::zone_tests` получает запрет на `crate::core::commands` для
  `infra`, `store` и `services`.
- Тесты сервисов не меняются: команды — тонкая оболочка без собственных
  правил, отдельного набора тестов не требуют.

## Отклонённые альтернативы

- **Оставить `lib.rs` и только разложить команды по разделам комментариями.**
  Размер не лечится, правило домена продолжает жить в точке сборки.
- **Вынести команды в `src/commands/` на уровне `lib.rs`.** Тот же слой,
  но рядом с `modules`; тогда `commands` не видит `Runtime` иначе как
  через `crate::`, и граница зон остаётся неописанной.
- **Сделать команды методами сервисов.** Привязывает домен к Tauri
  и ломает тестируемость сервисов без рантайма.
- **Разделить `lib.rs` по числу строк без правила.** Косметика: следующий
  файл снова обрастёт поведением.
