# ADR 0018: PrimeVue остаётся на мажоре 4

- **Статус:** принято
- **Дата:** 2026-11-12
- **Область:** `package.json`, `src/ui/primevue/theme.ts`, `src/app/main.ts`,
  `.agents/specs/archive/dnslookup.md`

## Контекст

ADR 0015 переводил проект на PrimeVue 5.0.5 с Community License. Проверка
лицензии в 5.0.5 оказалась не только сборочной: ключ содержит срок `exp`,
а `verifyLicense` при **каждом запуске** приложения сравнивает его с текущей
датой. Community-ключ действует 12 месяцев плюс 30 дней grace-периода;
после этого собранное приложение показывает баннер «Invalid PrimeUI License».

Владелец замораживает проект: собранная версия должна запускаться через год
и дальше без пересборки, продления ключа и лицензионных плашек. Это условие
Community License не выполняет, а Commercial License — платная.

PrimeVue 4.5.5 распространяется по MIT, не содержит проверки ключа и уже
установлен. Нужные для DNS возможности в нём есть: закреплённые колонки
и раскрытие строк в `DataTable`, `exportCSV`, `MultiSelect`, `Dialog`,
`InputGroup`.

## Решение

1. Проект остаётся на **PrimeVue 4.5.5** и **`@primeuix/themes` 2.0.3**.
   Версии точные, без `^`: случайный `npm install` не должен сменить мажор.
2. Лицензионный ключ не подключается. `license` в конфигурацию PrimeVue
   не передаётся, `.env.local` и `VITE_PRIMEUI_LICENSE` не используются.
3. ADR 0015 отменяется. Правило ADR 0013 («мажор зафиксирован на 4»)
   возвращается в силу.
4. DNS пишется на API мажора 4: `MultiSelect` для выбора серверов,
   `DataTable` с `scrollable`, `frozen`, `expandedRowKeys`, `#expansion`
   и `exportCSV`. Компоненты v5 (`Select multiple`, `InputTags`,
   `ToggleSwitch`, `Popover`) не используются.
5. Код не «готовится» к v5 заранее: миграция возможна только осознанным
   решением с новым ADR и действующей лицензией.

## Почему так

- **MIT без рантайм-проверок.** Собранное приложение работает столько,
  сколько нужно, без сети и без даты в ключе.
- **Функциональности v4 хватает.** DNS не использует ничего, что появилось
  только в v5; таблица, фильтры, раскрытие и CSV доступны в 4.5.5.
- **Замораживание — главное требование.** Ежегодное продление Community
  и пересборка ему противоречат, а Commercial ради личного инструмента
  не оправдан.
- **Откат дешёвый.** Код DNS ещё не написан, оболочка на v4 работает;
  фактически возвращается только документация.

## Последствия

- PrimeVue 4 больше не получает обновлений. Это принятая цена стабильности;
  при необходимости обновление оформляется отдельным ADR.
- Устаревшие API v4 (`MultiSelect`, свойства `label`/`icon` у `Button`)
  остаются рабочими. Новый код использует их там, где это естественно,
  и не тащит замены из v5.
- В проекте нет `.env.local`, ключей и баннера лицензии; сборка остаётся
  переносимой.
- ADR 0015 сохраняется как история решения и помечается заменённым.

## Отклонённые альтернативы

- **PrimeVue 5 с Community License.** Ключ истекает через 12 месяцев,
  приложение после этого показывает баннер; для замороженной сборки
  не подходит.
- **PrimeVue 5 с Commercial License.** Снимает проблему срока, но требует
  денег и не даёт ничего сверх v4 для задач проекта.
- **Остаться на v5 без ключа.** Баннер в закрытом shadow root виден всегда
  и не скрывается стилями; нарушение лицензии.
- **Держать v4 и v5 одновременно.** Две версии в одном бандле: конфликт
  стилей и символов, двойной вес, лишняя сложность.
