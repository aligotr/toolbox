# ToolBox

Портативный рабочий стол для сетевых и диагностических задач: Tauri 2
(ядро на Rust) и Vue 3 (интерфейс). Настройки, профили и журналы лежат
рядом с программой, а не в системных каталогах: папку можно перенести
на другую машину вместе с данными.

## Требования

- Windows с WebView2 (в Windows 10 и 11 он уже стоит) — основная платформа;
  Tauri собирает и под Linux, и под macOS, но приложение проверялось
  на Windows.
- [Node.js](https://nodejs.org/) 22.12 или новее — этого требует Vite 8.
- [Rust](https://rustup.rs/) stable: код на редакции 2024.
- Системные зависимости Tauri — по
  [официальной инструкции](https://tauri.app/start/prerequisites/).

## Запуск

```powershell
npm install
npm run tauri dev
```

Сборка установщика и portable-варианта:

```powershell
npm run tauri build
```

Проверки перед коммитом — одной командой:

```powershell
npm run verify
```

Она запускает тесты интерфейса (`npm run test`), линт (`npm run lint`:
ESLint и проверку формата Prettier) и сборку (`npm run build`: границы зон,
полнота словаря, типы, Vite), затем `cargo check` и `cargo test --lib`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| **DNSlookup** | Проверяет и сравнивает ответы DNS-серверов: строки доменов, несколько серверов, типы записей, фильтры и выгрузка в CSV. Разные вкладки — разные наборы доменов. |
| **Busprobe** | Самопроверка шины: путь сообщения, задержка, учебная цепочка запроса и ответа. |

Список инструментов собирается в `src/app/tools.ts`; новый инструмент
подключается одной записью реестра.

## Где лежат данные

Корень — папка с исполняемым файлом (в режиме разработки это
`src-tauri/target/debug/`). Структура:

```text
local/
  settings.json      настройки: лог, окно, язык, активный профиль
  workspace.json     открытые вкладки, колонки и активная вкладка
  logs/              журналы приложения
  languages/         внешние словари интерфейса
  trash/             корзина: удалённые профили, пресеты и данные
profiles/
  <id>/
    profile.json     название профиля
    presets/         пресеты инструментов
    data/            данные инструментов
```

Файлы можно править руками, пока приложение закрыто. Битый файл
не оставляет пустое окно: ядро откатывается к безопасному состоянию
и пишет причину в журнал.

## Профиль и рабочее пространство

**Профиль** — отдельный набор пресетов и данных инструментов. Активный
профиль один; переключение применяется после перезапуска, потому что
сервисы открывают папку профиля при старте. Удаление переносит папку
в корзину, а активный профиль удалить нельзя — сначала переключение.

**Рабочее пространство** — открытые вкладки, их колонки и активная вкладка.
Оно восстанавливается между запусками из `local/workspace.json`. Журнал
и настройки — одиночные вкладки: они открываются в одном экземпляре.
У вкладки есть «перезапуск»: та же раскладка, но свежие данные инструмента.

**Язык** переключается в разделе «Настройки → Интерфейс». Русский словарь
встроен и обязан быть полным; английский ставится рядом при первом запуске
и правится как обычный файл в `local/languages/`.

## Устройство

```text
src/
  contracts/    типы обмена: без поведения, Vue и Tauri
  core/         ядро интерфейса: infra ← services, правила без Vue
  ui/           тема и общие элементы
  workbench/    оболочка: сайдбар, вкладки, сетка
  tools/        инструменты: dnslookup, busprobe
  app/          точка сборки: реестр инструментов и корневой экран
src-tauri/      ядро Rust: infra ← store ← services ← commands
docs/agents/    как вести задачи, доменные документы и таблицы
.agents/        правила проекта и принятые решения (ADR)
```

Архитектурные решения не переписываются: новое оформляется отдельным ADR
в `.agents/decisions/`. Правила для правок — `AGENTS.md` и `.agents/rules/`.
