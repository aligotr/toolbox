# ToolBox

Портативный рабочий стол для сетевых и диагностических задач. Приложение
для Windows: настройки, профили и журналы лежат рядом с исполняемым файлом,
поэтому папку можно перенести на другую машину вместе с данными.

## Инструменты

- **DNSlookup** - проверка и сравнение ответов DNS-серверов: списки доменов,
  свои серверы, типы записей, фильтры и выгрузка в CSV.
- **Ping** - проверка отклика узлов по ICMP: домены и IP-адреса, IPv4 и IPv6,
  период и число пакетов, сводка по адресам, пакеты в раскрытии и две
  выгрузки CSV.
- **Busprobe** - учебная демонстрация шины: запрос, путь сообщения и ответ.

## Запуск

Нужны Windows с WebView2, Node.js 22.12 или новее, Rust stable и системные
зависимости Tauri.

```powershell
npm install
npm run tauri dev
```

- `npm run tauri build` - полная сборка с установщиками MSI и NSIS.
- `npm run tauri build -- --no-bundle` - только портативный `ToolBox.exe`.
- Релизный архив - `ToolBox_v<версия>.zip`; внутри `ToolBox.exe`,
  `README.txt` и `LICENSE` без вложенной папки. Собирает
  `npm run release:archive`, шаблон README - `scripts/release-readme.txt`.
- `npm run verify` - проверки перед коммитом: тесты, линт, сборка,
  `cargo check` и `cargo test`.

## Данные

Папка `local/` принадлежит машине: её не синхронизируют и не переносят.
Профили в `profiles/` переносятся вместе с папкой программы.
