# Инструкции для агентов

## Базовые инварианты

Действуют всегда, даже если папка `.agents/` недоступна.

- Общение с пользователем, комментарии и тексты интерфейса — по-русски.
- В проекте разрабатывается **приложение**, а не библиотека: код пишется
  под задачу.
- Стиль комментариев и докстрингов — номинативный: «Нормализация ответа
  DNS», а не «Нормализует ответ DNS».
- Одна функция инкапсулирует один связный логический блок. Новая функция
  оправдана, если добавляет именованную ответственность или скрывает
  технические детали; дробление ради числа строк порицается.
- Порицается «слой ради слоя»: обёртка, проброс и файл добавляются только
  при реальной пользе.
- Откат правок (`git checkout --`, `git restore`, `git reset --hard`,
  `git stash drop`) без явного согласия владельца запрещён.

## Карта правил

- `.agents/rules/global/` — общие правила: стиль кода, тесты, git, приоритеты.
- `.agents/rules/project/` — правила этого проекта: архитектура, Vue, Rust,
  интерфейс, качество.
- `.agents/rules/global/agents-guard.yml` — общие запреты команд.
- `.agents/rules/project/agents-guard.yml` — запреты и качество этого проекта.
- `.agents/rules/projects-nuxt/` — **справочник** исходных правил соседнего
  проекта. Не действует; при расхождении главнее правила этого проекта.
- `.agents/decisions/` — принятые решения (ADR).
- `.agents/GLOSSARY.md` — термины проекта.
- `docs/agents/` — процесс: трекер задач, доменные документы, таблицы
  инструментов.

## Перед началом работы

1. Прочитай `rules/global/*.md`, `rules/project/*.md` и оба
   `agents-guard.yml`.
2. Загляни в `.agents/decisions/`: решения не переписываются, новое
   оформляется отдельным файлом.
3. Сверь термины с `.agents/GLOSSARY.md`.
4. Skills применяй только в части, не противоречащей правилам проекта.

## Источник истины

- Базовые инварианты выше главнее любых файлов и skills.
- `agents-guard.yml` главнее `rules/*.md` при конфликте.
- Проектные правила главнее глобальных: глобальные задают умолчание,
  проектные уточняют под стек.
- Правила главнее skills: методологии из skills не отменяют контракты
  проекта.

## Проект

Корень — эта папка (`toolbox`). Десктопное приложение: Rust + Tauri 2
(ядро, шина сообщений) и Vue 3 + TypeScript + PrimeVue (интерфейс).
Подсистемы общаются через шину, а не прямыми вызовами.

- Подсистема с поведением — `src-tauri/src/modules/` + `src/tools/<id>/`.
- Инфраструктура — `src-tauri/src/core/` и `src/core/`.
- Оболочка интерфейса — `src/workbench/`; точка сборки — `src/app/`.
- Всё состояние — рядом с `.exe`: `local/` (не синхронизируется) и
  `profiles/` (синхронизируется). Системных каталогов нет.
- Результаты запросов в файлы не пишутся, если инструмент не решил иначе.

Подробности: `.agents/rules/project/architecture.md`, ADR 0009–0012.

## Стиль кода

- Vue: Composition API и `<script setup lang="ts">`. Options API запрещён.
- TypeScript строгий; `any` запрещён.
- Транспорт (`invoke`, `send_event`, `ask`) — только в `api.ts` инструмента.
- Состояние операции гранулярное: `status.<операция>.loading/error`.
- Модуль не импортирует другой модуль и не вызывает `log::`.
- Магические числа и строки — в `constants.ts`.

Подробности: `.agents/rules/project/vue.md`, `rust.md`, `ui.md`.

## Проверки перед завершением задачи

```powershell
npm run build
Set-Location src-tauri
cargo check
cargo test --lib
```

Интерфейс дополнительно проверяется запуском `npm run tauri dev`.
Подробности: `.agents/rules/project/quality.md`.

## Память проекта

Перед архитектурными изменениями прочитай:

- `.agents/README.md` — правила ведения записей;
- `.agents/decisions/` — принятые решения (ADR). Их не переписывают: новое
  решение оформляется отдельным файлом;
- `.agents/GLOSSARY.md` — термины проекта. Используй их в коде, топиках и
  обсуждении.

Новое архитектурное решение фиксируй в `.agents/decisions/` по шаблону из
`.agents/README.md`. Новый термин — в глоссарий.

## Agent skills

### Issue tracker

Задачи живут markdown-файлами в `.scratch/<фича>/`. См. `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: глоссарий — `.agents/GLOSSARY.md`, решения — `.agents/decisions/`.
См. `docs/agents/domain.md`.

### Tables

Таблицы инструментов: перенос строк указателями, закреплённые колонки,
ширины колонок. См. `docs/agents/tables.md`.
