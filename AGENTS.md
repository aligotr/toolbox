# AGENTS.md — правила для AI-агентов

## Базовые инварианты

- Общение с пользователем: русский
- В проекте разрабатывается приложение, не библиотека
- Стиль кода, комментарии и докстринги: номинативный стиль
- Длинные тире (em dash, U+2014) не используются в новых и изменяемых
  текстах: вместо них обычный дефис.
  Правило распространяется на код, комментарии, документацию, тексты
  интерфейса и сообщения коммитов
- Одна функция инкапсулирует один связный логический блок действий;
  функции-оркестраторы могут координировать несколько таких блоков, но
  не реализуют их детали. Новая функция оправдана только если она добавляет
  именованную ответственность, скрывает технические детали или делает
  сценарий читаемее; дробление ради уменьшения числа строк не рекомендуется
  и порицается
- Git: Запрещено откатывать (`git checkout --`, `git restore`,
  `git reset --hard`, `git stash drop`) без явного согласия пользователя

## Карта (если папка `.agents/` существует)

- Глобальные правила: `.agents/rules/global/`
- Проектные правила: `.agents/rules/project/`
- Правила интерфейса: `.agents/rules/project/ui/` (устройство стилей, принципы
  вида, элементы)
- Глобальные машиночитаемые запреты: `.agents/rules/global/agents-guard.yml`
- Проектные машиночитаемые запреты: `.agents/rules/project/agents-guard.yml`
- Подробные правила приоритетов: `.agents/rules/global/priorities.md`
- MCP-контекст библиотек: `.agents/mcp/<library>/` (если папка заведена)
- Skills: `.agents/skills/`

## Перед началом работы

1. Если `.agents/` существует — изучи `rules/global/*.md`,
   `rules/project/*.md`, `rules/project/*/*.md` и оба `agents-guard.yml`
2. Если `.agents/` отсутствует — соблюдай базовые инварианты выше
3. Если `.agents/mcp/` существует — посмотри названия подпапок и выбери
   релевантные для задачи библиотеки
4. Skills из `.agents/skills/` применяй только после проверки на
   совместимость с `rules/*.md`. Противоречащую правилам часть skill
   игнорируй

## Источник истины

- Правила из `rules/*.md` и `agents-guard.yml` **дополняют** друг друга
- При **конфликте** `agents-guard.yml` главнее
- Базовые инварианты этого файла **всегда** главнее любых правил в файлах
- Правила из `rules/*.md` и `agents-guard.yml` **главнее любых skills**:
  встроенные в skill методологии, шаблоны и процессы применяются только
  в части, не противоречащей этим правилам. При конфликте — следуй правилам,
  а не skill
- Skills — это инструменты под управлением правил, а не источник методологии
- Подробности и примеры: `.agents/rules/global/priorities.md`

## Версии

- Схема - `год.месяц.номер` (CalVer): `26.11.0` - первый выпуск ноября
  2026, `26.11.1` - следующий в том же месяце, `27.1.0` - первый выпуск
  января 2027.
- Третья часть считает выпуски месяца, а не дни: в одном месяце их может
  быть сколько угодно.
- Ведущих нулей нет: `26.1.0`, а не `26.01.00`. Точки - разделители
  частей, и каждая часть - обычное число.
- Версия одна везде, где объявлена: манифесты, конфигурация сборки и
  файлы блокировок не расходятся.
- Полный год в первой части не годится: многие форматы пакетов
  ограничивают major и minor (часто до 255) и не принимают pre-release
  и build-метаданные.
