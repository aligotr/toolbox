# Issue tracker: Local Markdown

Задачи и спеки этого проекта живут markdown-файлами в `.scratch/`.

## Соглашения

- Одна фича — одна папка: `.scratch/<feature-slug>/`
- Спека — `.scratch/<feature-slug>/spec.md`
- Тикеты реализации — по файлу на тикет:
  `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, нумерация с `01`,
  без общего файла со всеми тикетами
- Комментарии дописываются в конец файла под заголовком `## Comments`

## Когда скил говорит «опубликуй в трекер»

Создать новый файл в `.scratch/<feature-slug>/`, при необходимости создав папку.

## Когда скил говорит «прочитай тикет»

Прочитать файл по указанному пути. Пользователь обычно передаёт путь или номер.

## Хранение

`.scratch/` коммитится вместе с кодом и не входит в `.gitignore`: задача —
часть истории решения, а не временный файл. Закрытая задача остаётся
на месте, по ней видно, что и почему менялось. Папку удаляют только вместе
с отказом от её результата, и это оформляется отдельным решением.

## Блокировки

Строка `Blocked by: NN, NN` в начале файла. Тикет разблокирован, когда все
перечисленные в ней файлы закрыты.
